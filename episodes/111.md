## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
count = 3
label = f"Blocks: {count}"
print(label)
```

Expected terminal output:

```text
Blocks: 3
```

The f prefix enables interpolation. {count} evaluates count when the f-string expression runs; the resulting string does not remain linked to the variable.

## Change one input

```python
count = 5
label = f"Blocks: {count}"
print(label)
```

Expected terminal output:

```text
Blocks: 5
```
