# Episode 40: Which Path Finds the Star? A Decision Tree

Prepared; not yet publicly released.

**Concept:** decision trees  
**Learning goal:** A decision tree uses questions to choose a path.

Two signs help Klic choose the path to a blue star. A decision tree uses questions to choose a path.

## Learning path

Earlier lessons: 28. Revisit these ideas before trying this activity.

## Try it together

Make red-star, blue-circle and blue-star cards. Ask Is it blue? then Is it a star?

## Check understanding

**Ask:** Which two yes answers reach the blue star?

**Answer:** Yes to blue and yes to star.
