# Episode 48: Does Klic Have Enough? Python Comparisons

*Companion guide prepared; video release is pending.*

**Learning goal:** Greater than or equal compares values and produces True or False; it does not change the count.

**Prerequisites:** [Episode 7](./07.md), [Episode 46](./46.md).

## Try the real Python

Run this in a local Python 3 environment with a trusted grown-up. The terminal displays the output; the code does not move story props.

```python
stars = 2
print(stars >= 3)
```

Expected terminal output:

```text
False
```

## Change one thing

Predict the result before running this fresh example.

```python
stars = 3
print(stars >= 3)
```

Expected terminal output:

```text
True
```

## Try it together

Test two, three and four against the same three-star threshold. Write the predicted output on paper first, run with a grown-up, and compare. Use fictional names and practice values.

## Read the important line

`stars = 2` stores the number two. `>=` asks whether the left number is greater than **or equal to** the right number. `print` displays the answer. Three is equal to three, so the second answer is `True`; two is smaller, so the first answer is `False`. A comparison checks a value without updating it.

Try `stars = 4`: the answer is also `True`.
