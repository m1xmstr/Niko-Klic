**Learning goal:** Extract the explicit port number independently from a URL hostname.

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
from urllib.parse import urlsplit
link = "https://example.com:8000/map"
parts = urlsplit(link)
print(parts.hostname)
print(parts.port)
```

Expected terminal output:

```text
example.com
8000
```

parts.port reads an explicit port number as an integer. A port helps identify an endpoint on a host, but this parser does not connect, test reachability, or identify the service. With no explicit port, this property is None.

## Change one input

```python
from urllib.parse import urlsplit
link = "https://example.com:8080/map"
parts = urlsplit(link)
print(parts.hostname)
print(parts.port)
```

Expected terminal output:

```text
example.com
8080
```

## What the story shows

Python parses a fictional URL only. The cabinet is a visual analogy, not network equipment. No connection or service availability test is performed.
