## Reproduce safely

Run only against an explicitly limited localhost with no escalation. The example only prints a debug message; it does not print paper or control a welcome screen. Save this full playbook as `greeting.yml` in a fresh practice folder:

```yaml
- hosts: localhost
  connection: local
  gather_facts: false
  vars:
    guest: Klic
  tasks:
    - ansible.builtin.debug:
        msg: "Hello, {{ guest }}!"
```

```sh
ansible-playbook -i localhost, --limit localhost greeting.yml
```

Expected message: `Hello, Klic!`. Replace the template with literal "Hello, guest!" to reproduce the mistake. Then restore the template and change only guest to Nico: `Hello, Nico!` The video A/B prefixes are choice labels, not YAML lines to copy.
