# Episode 92: What Does Ready Mean? Python Named Conditions

Video in preparation; no native schedule yet.

**Learning goal:** Store two combined pretend checks in a readable Boolean variable, then change one flag and rerun.

**Prerequisites:** [Lesson 62](./62.md), [Lesson 91](./91.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
has_tool = True
clear_space = True
can_start = has_tool and clear_space
print(can_start)
```

Expected terminal output:

```text
True
```

can_start = has_tool and clear_space stores the Boolean result of and. Both values must be True. The name does not inspect a real space or update automatically.

## Change one input

```python
has_tool = True
clear_space = False
can_start = has_tool and clear_space
print(can_start)
```

Expected terminal output:

```text
False
```

## What the story shows

These are manually initialized pretend flags. Python prints True or False; it does not see the mat, inspect tools, authorize a real activity, or change the world.

## Try it together

With a grown-up, run the direct-expression and named-condition versions. Both print True. Change clear_space to False and rerun the complete program: False. Restore it and change has_tool to False: False again. Use pretend flags only; real activities always need a grown-up check.
