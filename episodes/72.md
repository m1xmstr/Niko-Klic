# Episode 72: Will the Countdown Stop? Python while

Video in preparation; not uploaded or scheduled. These Python examples have been executed locally and do not imply media approval or release.

**Learning goal:** Repeat a block while a condition is True and update the counter so the loop stops.

**Prerequisites:** [Episode 46](./46.md), [Episode 48](./48.md), [Episode 50](./50.md).

## Run real Python

With a trusted grown-up, use a local Python 3 environment. Predict the terminal output before running the full example. No account or private information is needed.

```python
remaining = 3
while remaining > 0:
    print(remaining)
    remaining = remaining - 1
```

Expected output:

```text
3
2
1
```

remaining = remaining - 1 reduces the counter inside the loop. At zero, remaining > 0 is False, so zero is not printed.

## Change one thing

Run this fresh example separately:

```python
remaining = 2
while remaining > 0:
    print(remaining)
    remaining = remaining - 1
```

Expected output:

