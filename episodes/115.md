**Learning goal:** Pair each list item with a counter using enumerate.

**Prerequisites:** [Episode 54](54.md), [Episode 58](58.md).

## Working Python

With a trusted grown-up, run this complete example in a local Python3 environment. Use fictional values only.

```python
toys = ["kite", "boat"]
for number, toy in enumerate(toys, 1):
    print(number, toy)
```

Expected terminal output:

```text
1 kite
2 boat
```

enumerate(toys, 1) yields counter-item pairs beginning at 1. This does not change zero-based list indices.

## Change one thing

```python
toys = ["drum", "boat"]
for number, toy in enumerate(toys, 1):
    print(number, toy)
```

Expected output:

```text
1 drum
2 boat
```

## Story and practice

Nico sets a toy kite in a small display cradle, rotates a numbered ticket holder, then swaps the toy for a drum. Klic slides a wooden boat along the counter, clips a blank ticket to its stand, then checks the two stands. Props illustrate the idea; print displays terminal text and does not control hardware.

With a grown-up, add "ball" as a third item and predict 3 ball on the third line. Then change the start argument to 5 and predict 5, 6, 7.

**Ask:** Are list indices now one-based?

**Answer:** No. The enumerate counter can start at one while list indices still start at zero.
