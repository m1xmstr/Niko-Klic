# Episode 68: No Color Yet? Python get Has a Backup

Video release pending. This guide contains prepared Python examples; it is not a claim that the video is published.

**Learning goal:** Retrieve a stored value when its key exists, or use an explicit fallback value when the key is absent.

**Prerequisites:** [Episode47](./47.md), [Episode59](./59.md), [Episode60](./60.md), [Episode66](./66.md).

## Run real Python

With a trusted grown-up, use a local Python 3 environment. First predict the terminal output. Python prints text; the story props are moved by the characters. No account or personal information is needed.

```python
settings = {}
print(settings.get('color', 'white'))
```

Expected terminal output:

```text
white
```

get asks for color. The second argument, white, is the fallback if that key is missing. Empty braces create an empty dictionary.

## Change one thing

Run this fresh example separately and compare:

```python
settings = {'color': 'blue'}
print(settings.get('color', 'white'))
```

Expected terminal output:

```text
blue
```

## What the story shows

get returns a value and print displays it. It does not add the fallback key to the dictionary or paint a lantern. The characters apply the illustrative sleeve by hand.

## Try it together

Try a fictional toy color, then remove its key and predict the fallback. Print settings afterward to check it was not modified. A grown-up can write the two possible results on paper, pause for your prediction, and help you compare with the terminal. Use only made-up practice values.

**Ask:** Did get add a color key when it returned white?

**Answer:** No. It returned the fallback without changing the empty dictionary.
