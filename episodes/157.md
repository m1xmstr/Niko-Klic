## Play together without a computer

Draw a blue triangle and a gold circle. Label the triangle TRIANGLE and the circle CIRCLE. Now draw a blue circle. Ask your child: "Which example matches its color? Which matches its shape?" Swap roles and try a gold triangle.

The point is to notice what the model compares, not to memorize a right answer. Ask: "What else would you test before trusting this sorter?"

## What actually ran

A Python nearest-neighbor toy classifier stored two labeled examples. It used a distance of zero for an equal selected feature and one otherwise. The closest examples voted on the label; a disagreement returned UNKNOWN.

| Same blue-circle input | Selected feature | Recorded output |
| --- | --- | --- |
| First run | color | TRIANGLE |
| Changed run | shape | CIRCLE |
| Fresh replay | color | TRIANGLE |

We also tested all four blue/gold and triangle/circle combinations. Color matching was correct in two of four; shape matching was correct in four of four. Reversing the example order preserved these predictions.

These are hand-entered color and shape fields, **not image recognition**. Supplying the shape makes this a deliberately simple demonstration of feature choice. Four tiny tests do not establish general AI accuracy or fairness.

## Runnable example

With a grown-up, save this as `sticker.py` in a practice folder and run `python3 sticker.py`. It reads no files and makes no network requests.

```python
"""Categorical nearest-neighbor classifier: fit stores labeled examples."""
class ToyNearestNeighbor:
 def fit(self, examples):
  self.examples=[dict(x) for x in examples]
  return self
 def predict(self, item, feature):
  distances=[int(x[feature]!=item[feature]) for x in self.examples]
  nearest=[x['label'] for x,d in zip(self.examples,distances) if d==min(distances)]
  return nearest[0] if len(set(nearest))==1 else 'UNKNOWN'

examples = [
    {"color": "blue", "shape": "triangle", "label": "TRIANGLE"},
    {"color": "gold", "shape": "circle", "label": "CIRCLE"},
]
model = ToyNearestNeighbor().fit(examples)
sticker = {"color": "blue", "shape": "circle"}
print(model.predict(sticker, feature="color"))
print(model.predict(sticker, feature="shape"))
```

Expected output:

```text
TRIANGLE
CIRCLE
```
