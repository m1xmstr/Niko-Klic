# Episode 70: Either Ticket Works! Python or

Video release pending. This guide contains prepared Python examples; it is not a claim that the video is published.

**Learning goal:** Use or when at least one of two Boolean checks must be True.

**Prerequisites:** [Episode48](./48.md), [Episode62](./62.md).

## Run real Python

With a trusted grown-up, use a local Python 3 environment. First predict the terminal output. Python prints text; the story props are moved by the characters. No account or personal information is needed.

```python
ticket = False
pass_card = True
print(ticket or pass_card)
```

Expected terminal output:

```text
True
```

or is True if at least one input is True; both False gives False. The stored inputs do not change.

## Change one thing

Run this fresh example separately and compare:

```python
ticket = False
pass_card = False
print(ticket or pass_card)
```

Expected terminal output:

```text
False
```

## What the story shows

Pretend values teach a Boolean operation; Python does not open the theatre, scan tickets, or implement real access security.

## Try it together

Use fictional ticket and pass flags in a toy game. Try both True, then both False, and compare the terminal. A grown-up can write the two possible results on paper, pause for your prediction, and help you compare with the terminal. Use only made-up practice values.

**Ask:** Why does one True flag make or True in this example?

**Answer:** For these Boolean flags, either True is enough. Both False gives False.
