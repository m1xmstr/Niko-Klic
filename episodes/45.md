# Episode 45: One Missing Quote Stops Python!

[Watch Episode 45](https://www.youtube.com/shorts/L9pZu6YMfFc).

**Learning goal:** A missing closing quote prevents this program from running; read the error, repair and rerun.

## Learning path

Prerequisites: [Episode 44](44.md).

## Run the code

```python
print("Star ready!")
```

Terminal output:

```text
Star ready!
```

## Change one thing

```python
print("Moon ready!")
```

Terminal output:

```text
Moon ready!
```

## Find the bug

```python
print("Star ready!)
```

The closing quote is missing. This produces a `SyntaxError` and no program output. Add the quote before the closing parenthesis, then rerun. Exact error wording may vary by Python version.

## Try it together

Circle the opening and closing quotes on a printed code card. An adult can help run this in a local Python 3 editor. Offline, write each line on paper and predict the terminal output before uncovering it.
