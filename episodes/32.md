# Episode 32: Where Did the Star Go? Find the Output

Prepared; not yet publicly released.

**Concept:** output  
**Learning goal:** Input goes in. Output is the result we get.

Klic chooses a star but a screen is blank. Input goes in. Output is the result we get.

## Learning path

Earlier lessons: 9, 10. Revisit these ideas before trying this activity.

## Try it together

Choose a pretend shape input and draw the matching output on paper.

## Check understanding

**Ask:** What is the output in this story?

**Answer:** The star picture that appears on the screen.

## For grown-ups

Colored blocks are simplified pseudocode. Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed for these activities.
