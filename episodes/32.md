# Episode 32: Klic Catches the Output!

[Watch the episode](https://youtube.com/shorts/P4RcQ6qRVec)

**Concept:** output  
**Learning goal:** Output is the result. On a screen, or on paper!

Output is what a computer gives us: Nico runs a printer while Klic catches the finished star picture.

## Learning path

Earlier lessons: 9, 10. Revisit these ideas before trying this activity.

## Story code

```text
DRAW STAR > PRINT PICTURE
```

These are simplified pseudocode instructions.

## Try it together

Draw a star on a pretend computer screen. Hand a paper copy to a helper and name that copy as output.

## Check understanding

**Ask:** What is the output in this story?

**Answer:** The printed star picture that Klic catches.

## For grown-ups

Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed.
