# Episode 37: Too Many Blocks? Try Efficient Code

Prepared; not yet publicly released.

**Concept:** efficient code  
**Learning goal:** A loop can describe repeated work with fewer instructions.

Three copies of the same sparkle instruction crowd the screen. A loop can describe repeated work with fewer instructions.

## Learning path

Earlier lessons: 2, 19. Revisit these ideas before trying this activity.

## Try it together

Compare three SPARKLE cards with one REPEAT 3: SPARKLE card. Act out both.

## Check understanding

**Ask:** Does using fewer blocks change the number of sparkles here?

**Answer:** No. Both produce exactly three sparkles. Fewer blocks does not always mean faster execution.

## For grown-ups

Colored blocks are simplified pseudocode. Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed for these activities.
