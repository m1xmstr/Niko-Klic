# Episode 37: Klic Drops the Code! A Smarter Loop

[Watch Episode 37](https://www.youtube.com/shorts/D7f1kIIzSno)

**Concept:** efficient code  
**Learning goal:** Fewer blocks, same result. That is our shortcut.

Efficient code helps Nico replace three identical sparkle cards with one repeat instruction that produces the same three sparkles.

## Learning path

Earlier lessons: 2, 19. Revisit these ideas before trying this activity.

## Story code

```text
REPEAT 3: >     SPARKLE
```

These are simplified pseudocode instructions.

## Try it together

Compare three SPARKLE cards with one REPEAT 3: SPARKLE card. Act out both.

## Check understanding

**Ask:** Does using fewer blocks change the number of sparkles here?

**Answer:** No. Both produce exactly three sparkles. Fewer blocks does not always mean faster execution.

## For grown-ups

Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed.
