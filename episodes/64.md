# Episode 64 — Can a Function Send a Number Back? Python `return`

**[Watch Episode 64](https://youtube.com/shorts/xdlI_BGsHTA)** These working examples accompany this lesson.

Python `return` sends a result from a function back to the place that called it. You can store that result and use it later.

Learning objective: call a function with a number, follow its returned result into a variable, and distinguish returning a value from printing text.

Prerequisites: [function inputs in Episode 51](51.md) and [variables in Episode 46](46.md).

## Send a value back

```python
def add_one(number):
    return number + 1
answer = add_one(2)
print(answer)
```

Expected terminal output:

```text
3
```

1. `def` creates the function. Its body runs when we call it.
2. `add_one(2)` calls it with `number` set to `2`.
3. `return number + 1` calculates `3` and sends that value back to the caller.
4. `answer = ...` stores the returned value in `answer`.
5. `print(answer)` displays `3` in the terminal.

Keep the colon after `def` and four spaces before `return`. The call and `print` are outside the function, so those lines are not indented.

## Change the input

Predict the returned value, then run:

```python
def add_one(number):
    return number + 1
answer = add_one(4)
print(answer)
```

Expected terminal output:

```text
5
```

The same function takes a different input. `4 + 1` gives `5`, which is stored in `answer` before being printed.

## `return` and `print` do different jobs

`return` gives a value to the caller. `print` displays text. Calling this function without `print` produces no terminal text:

```python
def add_one(number):
    return number + 1
answer = add_one(2)
```

Expected terminal output: nothing. `answer` still contains `3`.

Use a returned value again:

```python
def add_one(number):
    return number + 1
score = add_one(2)
next_score = add_one(score)
print(next_score)
```

Expected terminal output:

```text
4
```

The first call returns `3`. The second call uses that result as its input and returns `4`. In a game, a function can calculate a new score for the rest of your program to use.
