# Episode 89: Too Many Cards for Five Slots! Python min

Video in preparation; no native schedule yet.

**Learning goal:** Cap a nonnegative requested count at a fixed capacity with min, then test a smaller request.

**Prerequisites:** [Lesson 65](./65.md), [Lesson 84](./84.md), [Lesson 87](./87.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
requested = 7
capacity = 5
allowed = min(requested, capacity)
print(allowed)
```

Expected terminal output:

```text
5
```

min returns the smaller argument. It does not change requested or capacity. This example assumes nonnegative whole-number counts.

## Change one input

```python
requested = 3
capacity = 5
allowed = min(requested, capacity)
print(allowed)
```

Expected terminal output:

```text
3
```
