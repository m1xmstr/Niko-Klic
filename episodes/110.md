## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
length = 2.4
rounded = round(length)
print(rounded)
```

Expected terminal output:

```text
2
```

round(x) without ndigits returns the nearest integer, with ties to even. It does not mutate the original variable; binary float representation matters for other examples.

## Change one input

```python
length = 2.6
rounded = round(length)
print(rounded)
```

Expected terminal output:

