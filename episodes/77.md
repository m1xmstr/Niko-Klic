# Episode 77: Can One File Lend Its Function? Python Modules

Natively scheduled for **2026-10-12T10:00:00-05:00 (America/Chicago)**. Public playback and manual English captions will be checked after release.

**Learning goal:** Save a helper function in one Python file and import it from a second file in the same folder.

**Prerequisites:** [Lesson 52](./52.md), [Lesson 64](./64.md), [Lesson 75](./75.md), [Lesson 76](./76.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

### Save as `helpers.py`

```python
def double(n):
    return n * 2
```

### Save as `main.py`

```python
from helpers import double
print(double(3))
```

Save both files in the same new practice folder. Reopen to check them, then run `main.py`.

Expected terminal output:

```text
6
```

from helpers import double imports the function from helpers.py. Run main.py from the same practice folder; the import name omits .py.

## Change one input

### Save as `helpers.py`

```python
def double(n):
    return n * 2
```

### Save as `main.py`

```python
from helpers import double
print(double(4))
```

Save both files in the same new practice folder. Reopen to check them, then run `main.py`.

Expected terminal output:

```text
8
```
