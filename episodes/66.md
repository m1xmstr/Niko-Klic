# Episode 66 — Which Nickname Appears? Python Dictionary Lookup

**[Watch Episode 66](https://youtube.com/shorts/aUPBlr19wXk)** These examples accompany the upcoming lesson.

A Python dictionary lookup selects the value stored under a key. Here, we use only a made-up nickname for a pretend game.

Learning objective: look up one dictionary value, predict its terminal output, and compare the result after changing that value.

Prerequisites: [dictionaries in Episode 59](59.md) and [dictionary updates in Episode 60](60.md).

## Choose a fictional label

```python
profile = {'nickname': 'StarBot'}
print(profile['nickname'])
```

Expected terminal output:

```text
StarBot
```

- Curly braces `{}` create the dictionary.
- `'nickname'` is a **key**. `'StarBot'` is the **value** stored under that key.
- The colon `:` separates the key from its value.
- `profile['nickname']` uses square brackets to look up the value for that key.
- `print` displays the selected value in the terminal. It does not display the entire dictionary.

Keep the quotes around both text strings and around the key used in the lookup.

## Change the stored value

Predict the output, then run:

```python
profile = {'nickname': 'MoonBot'}
print(profile['nickname'])
```

Expected terminal output:

```text
MoonBot
```

The lookup still uses the key `'nickname'`. That key now holds a different value, so the terminal displays `MoonBot`.

## Change a value in an existing dictionary

This combines the earlier update lesson with the lookup:

```python
profile = {'nickname': 'StarBot'}
profile['nickname'] = 'MoonBot'
print(profile['nickname'])
```

Expected terminal output:

```text
MoonBot
```

## A lookup is not automatic privacy protection

The code selects a value to print. It does not secure a profile, decide whether a name is safe, or control who can see other information. We deliberately use fictional labels and never enter real names, addresses or passwords. Ask a trusted grown-up before sharing a player label or using a game or website.

Nico chooses a pretend nickname card. Klic puts a blank fictional envelope into a toy box. These props illustrate careful choices; the box is not a claim that Python has protected information. `print` displays terminal text and does not share it with an online game.

On paper, write **nickname** on one card and **StarBot** on another. Put them together as a key/value pair. A grown-up reads the key; you find its matching value. Replace the value card with **MoonBot** and try again. With a trusted grown-up, run the matching Python examples locally. Question: Why did the output change even though the lookup key stayed the same?

Answer: The value stored under `'nickname'` changed. Looking up the same key retrieves its current value.
