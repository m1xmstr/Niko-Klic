# Episode 93: Which Folder Holds the Note? Python Path

Video in preparation; no native schedule yet.

**Learning goal:** Build a relative Path and read its name and parent without creating or opening a file.

**Prerequisites:** [Lesson 76](./76.md), [Lesson 78](./78.md), [Lesson 79](./79.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
from pathlib import Path
p = Path("practice/note.txt")
print(p.name)
print(p.parent)
```

Expected terminal output:

```text
note.txt
practice
```

Path("practice/note.txt") describes a relative address. p.name returns the final filename; p.parent gives its parent path. Constructing Path does not create a file.

## Change one input

```python
from pathlib import Path
p = Path("practice/star.txt")
print(p.name)
print(p.parent)
```

Expected terminal output:

```text
star.txt
practice
```

## What the story shows

Python prints parts of a path. This example does not create, read, move or verify a file. A relative path is interpreted from the program’s working folder.

## Try it together

With a grown-up, run both versions in a fresh practice folder. The name changes to star.txt while the parent remains practice. Then change practice to sketches: star.txt and sketches appear. Check that no files or folders were created. Use pretend paths only.
