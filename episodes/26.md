# Episode 26: Name That Variable!

[Watch Episode 26](https://www.youtube.com/shorts/RLDQvN8yUps) — published October 7, 2026.

**Concept:** variable names  
**Learning goal:** Choose descriptive variable names that explain what values represent.

Two mystery boxes get meaningful labels. Exactly three stars move to STARS and one key moves to KEYS.

## Learning path

Episode 25 (a variable stores a value).

## Try it together

Draw three stars and one key on separate paper cards. Make two value labels: STARS = 3 and KEYS = 1. Match each label to its objects, then explain why the name helps.

## Check understanding

**Ask:** Which variable name helps us understand the value 3 here?

**Answer:** STARS, because the value 3 counts the three stars.
