# Episode 78: Will Our Note Still Be There? Python File Writing

Video in preparation; no native schedule yet.

**Learning goal:** Use with open to write a fictional word, close the file automatically and reopen it to verify persisted content.

**Prerequisites:** [Lesson 52](./52.md), [Lesson 77](./77.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
with open('note.txt', 'w') as note:
    note.write('Moon')
with open('note.txt') as note:
    print(note.read())
```

Expected terminal output:

```text
Moon
```

Mode 'w' creates a file or replaces its existing contents; use a new empty practice folder. with closes the file when its indented block ends.

## Change one input

```python
with open('note.txt', 'w') as note:
    note.write('Star')
with open('note.txt') as note:
    print(note.read())
```

Expected terminal output:

```text
Star
```

## What the story shows

The code saves a text file and then prints its reopened contents. The physical note is placed by hand, never by Python.

## Try it together

With a grown-up, create a new empty practice folder. Save this program as main.py, reopen the source to verify it, then run it. Open note.txt to verify Moon. Change Moon to Star in main.py, save and rerun; reopen note.txt to verify Star. Mode w replaces note.txt contents, so use only this disposable practice file and no private information.
