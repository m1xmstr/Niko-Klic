# Episode 54: Klic Drops His Toys! Build a Python List

[Watch Episode 54](https://youtube.com/shorts/WWEv2X9_OfI)

**Learning goal:** Use square brackets to group ordered values

**Prerequisites:** [Episode 47](./47.md).

## Try the real Python

Run this in a local Python 3 environment with a trusted grown-up. The terminal displays the output; the code does not move story props.

```python
toys = ['ball', 'kite']
print(toys)
```

Expected terminal output:

```text
['ball', 'kite']
```

## Change one thing

Predict the result before running this fresh example.

```python
toys = ['ball', 'car']
print(toys)
```

Expected terminal output:

```text
['ball', 'car']
```

## Try it together

Change the shown input, predict the result and compare with the terminal. Write the predicted output on paper first, run with a grown-up, and compare. Use fictional names and practice values.

## Read the important line

The outer square brackets make a list. The comma separates its two items. Quotes mean each item is text: `ball` has four letters but is still one item in this list. Python prints the stored items in their order. Changing the second item keeps the first item in place.

On paper, draw two boxes in a row. Write `ball` in the first and `kite` in the second. Replace only `kite` with `car`. Predict the printed list before asking a grown-up to help run the changed example.
