## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
from pathlib import Path
folder = Path("practice")
folder.mkdir(exist_ok=True)
print(folder.name)
print(folder.is_dir())
```

Expected terminal output:

```text
practice
True
```

folder.mkdir(exist_ok=True) creates the folder. If that directory already exists, exist_ok=True permits rerunning. It does not place any files inside. A file with the same name can still cause an error.
