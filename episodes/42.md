# Episode 42: Klic's App Is Stuck! Time for an Update

[Watch Episode 42](https://www.youtube.com/shorts/dPa7bK0Bt6s)

**Concept:** software update  
**Learning goal:** Ask a grown-up. Save, update, and test.

A software update can fix problems and improve safety. With a grown-up’s help, Nico and Klic save, update, and test a pretend drawing app.

## Learning path

Earlier lessons: Episodes 17 backups and 38 locking devices. Revisit these ideas before trying this activity.

## Story code

```text
GROWN-UP CHECKS > SAVE > UPDATE > TEST
```

These are simplified pseudocode instructions.

## Try it together

Ask a trusted grown-up to show the official update settings on a device. Talk through saving work and testing afterward.

## Check understanding

**Ask:** Who helps Klic check a software update?

**Answer:** A trusted grown-up. Save work, use a trusted update path, then test again.

## For grown-ups

Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed.
