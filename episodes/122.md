## Learning goal
Explain how labeled examples fit a tiny classifier, then check its prediction on a new example against the known label. A label is the answer attached to an example. A prediction is the model's proposed answer; it can be wrong.

## Story
At a twilight garden table, Nico slides a covered garden card into a holder. Klic lifts the answer flap after they predict. Their model calls size 4 PEA, but the hidden label is SUNFLOWER. They try another card, size 6: this time the prediction matches its SUNFLOWER label.

The four training cards and two test cards are fictional. Size uses made-up units. This is **not a method for identifying real plants or seeds**. Animated props show results recorded from a real tiny classifier; no robot or gardening hardware is controlled.

## Exact demonstration

| Use | Size | Known label | Model prediction |
|---|---:|---|---|
| Training |2|PEA|Not a test|
| Training |3|PEA|Not a test|
| Training |7|SUNFLOWER|Not a test|
| Training |8|SUNFLOWER|Not a test|
| New test |4|SUNFLOWER|PEA — wrong|
| New changed case |6|SUNFLOWER|SUNFLOWER — matches|

The group averages fitted from training are 2.5 and 7.5. Size 4 is nearer 2.5; size 6 is nearer 7.5. The test labels are used only to check predictions. They never enter training and we do not retrain between test cases. One correct answer out of two illustrates these two chosen cards only, not real-world accuracy.

## For grown-ups: reproduce the model
Python is an optional implementation detail here; the Short teaches labels and prediction checking, with no code displayed. Save this as `classifier.py` in an empty practice folder and run it with Python 3. It creates a small local `trained-model.json`, closes it, reopens it, and evaluates the same saved model. Use only fictional data.

```python
"""Fictional seed cards: training labels fit centroids; test labels only score predictions."""
import json
from pathlib import Path
from statistics import mean
training = {'PEA': [2, 3], 'SUNFLOWER': [7, 8]}
model = {label: mean(sizes) for label, sizes in training.items()}
path = Path(__file__).with_name('trained-model.json')
path.write_text(json.dumps(model, indent=2) + '\n')
model = json.loads(path.read_text())
def predict(size):
    # An exact tie chooses PEA because it is first in the training mapping.
    return min(model, key=lambda label: abs(size-model[label]))
print('TRAINING:', training)
print('SAVED AND REOPENED CENTROIDS:', model)
test_cards = [(4, 'SUNFLOWER'), (6, 'SUNFLOWER')]
correct = 0
for size, label in test_cards:
    guess = predict(size)
    matched = guess == label
    correct += matched
    print(f'Size {size}: prediction={guess}, label={label}, match={matched}')
print(f'Tiny test: {correct}/{len(test_cards)} correct; not real-world accuracy.')
assert model == {'PEA': 2.5, 'SUNFLOWER': 7.5}
assert predict(4)=='PEA' and predict(6)=='SUNFLOWER' and predict(5)=='PEA'
assert correct==1
```

Expected output:

```text

SAVED AND REOPENED CENTROIDS: {'PEA': 2.5, 'SUNFLOWER': 7.5}

Size 6: prediction=SUNFLOWER, label=SUNFLOWER, match=True
```

## Predict, reveal, explain

- **What does a training label tell us?** The known group for that example.
- **What will this model predict for size 4?** PEA, because 4 is closer to the PEA average 2.5 than the SUNFLOWER average 7.5.
- **Does that make the card a pea?** No. Its known SUNFLOWER label disagrees. A prediction is not a guaranteed fact.
- **What changes for size 6?** The same trained model predicts SUNFLOWER; the new card's label agrees.
- **Did the model learn the test labels?** No. We kept them out of training and only used them afterward to check.

## Grown-up-supported card activity
Make the four training cards in the table. Put their size on one side and group label on the other. Explain that the labels and sizes are invented. Make two separate test cards, 4 SUNFLOWER and 6 SUNFLOWER. Hide each test label, predict with the nearer group average, then reveal and compare. A grown-up can help with distances on a number line. Ask what information size alone leaves out. Do not use this toy model to identify real seeds, decide what to eat, or make safety decisions.

## Technical basis
This transparent standard-library example uses nearest-centroid classification: represent each class by its average and predict the nearest one. [scikit-learn's nearest-centroid explanation](https://scikit-learn.org/stable/modules/neighbors.html#nearest-centroid-classifier) describes the method. This example does not depend on or claim to execute scikit-learn. The fixed tie rule selects PEA at size 5.
