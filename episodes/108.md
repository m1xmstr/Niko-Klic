# Episode 108: Is Five a Word or a Number? Python int

Video in preparation; no native schedule yet.

**Learning goal:** Convert valid integer text before doing arithmetic.

**Prerequisites:** [Lesson 44](./44.md), [Lesson 47](./47.md), [Lesson 54](./54.md), [Lesson 57](./57.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
text = "5"
count = int(text)
print(count + 2)
```

Expected terminal output:

```text
7
```

int(text) parses valid integer text. Invalid text such as apple raises ValueError. This lesson uses initialized fictional strings, not personal input.

## Change one input
