**Objective:** Distinguish a rule written by a person from a tiny model fitted using labeled examples, even when both give the same answer.

**Prerequisites:** Know that computers follow instructions. Episodes 119 (Linux and operating systems) and 120 (Ansible automation) introduce related vocabulary. No coding knowledge is required to watch.

## The story

In a toy sorting playroom, Nico brings a size token to a ramp while Klic pulls the routing lever. Two decision methods agree about where it belongs. The props illustrate recorded results; they do not run a thinking machine or control real hardware.

A person writes **above 5 means BIG; otherwise SMALL**. Separately, our tiny classifier is fitted using labeled examples: **2 and 3 are SMALL; 7 and 8 are BIG**. It calculates each group's average and assigns a new size to the nearer average. Those fitted averages are 2.5 and 7.5. Exact ties use SMALL.

Some AI learns patterns from examples. Not every AI system learns this way. People choose the data, labels and method. A model is not a conscious character, and these four fictional examples do not establish real-world accuracy.

## Predict, change, check

- **Predict:** What will the model call size 6? **BIG**: 6 is closer to 7.5 than 2.5. The written rule also gives BIG.
- **Change:** Replace 6 with 4. **SMALL**: 4 is closer to 2.5. The written rule agrees again.
- **Did both methods learn?** No. The rule's threshold was written by a person. The classifier's averages were calculated from labeled examples. Matching outputs alone cannot tell us how a system was built.
- **Can a trained model make mistakes?** Yes. Labels, examples, design choices and unfamiliar inputs can all cause problems. Check new results.

## Grown-up reproducible demonstration

This standard-library Python implementation supports the AI concept; Python syntax is not the lesson. It implements nearest-centroid classification directly and does not use the scikit-learn package. Run in a new disposable local folder with a grown-up. It writes and reopens only `trained-model.json` in that folder. Use fictional values only.

```python
"""Tiny nearest-centroid classifier; fictional size labels, not a real-world AI test."""
import json
from pathlib import Path
from statistics import mean
training = {'SMALL': [2, 3], 'BIG': [7, 8]}
centroids = {label: mean(values) for label, values in training.items()}
model_path = Path(__file__).with_name('trained-model.json')
model_path.write_text(json.dumps(centroids, indent=2) + '\n')
model = json.loads(model_path.read_text())
def predict(size):
    # Stable label order makes exact ties SMALL.
    return min(model, key=lambda label: abs(size - model[label]))
def rule(size):
    return 'BIG' if size > 5 else 'SMALL'
print('TRAINING:', training)
print('SAVED AND REOPENED CENTROIDS:', model)
for size in [6, 4]:
    print(f'Size {size}: rule={rule(size)}, model={predict(size)}')
assert predict(6) == 'BIG' and predict(4) == 'SMALL'
assert predict(5) == 'SMALL'
```

```text
Size 4: rule=SMALL, model=SMALL
```
