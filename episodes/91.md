# Episode 91: What Does This Number Mean? Python Variable Names

Natively scheduled for **2026-10-14T10:10:00-05:00 (America/Chicago)**. Public playback and manual English captions will be checked after release.

**Learning goal:** Use meaningful snake_case names and units to explain a small time calculation, then change one value.

**Prerequisites:** [Lesson 44](./44.md), [Lesson 84](./84.md), [Lesson 90](./90.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
minutes_left = 9
break_minutes = 4
work_minutes = minutes_left - break_minutes
print(work_minutes)
```

Expected terminal output:

```text
5
```

work_minutes = minutes_left - break_minutes subtracts the planned break. Each name describes a value in minutes; underscores join words.

## Change one input

```python
minutes_left = 9
break_minutes = 2
work_minutes = minutes_left - break_minutes
print(work_minutes)
```

Expected terminal output:

```text
7
```

## What the story shows

These are pretend planning values. Python displays a number in the terminal; it does not run a timer or measure elapsed time.

## Try it together

With a grown-up, run the short-name and descriptive-name programs. Both display 5. Change break_minutes to 2 and expect 7. Restore 4 and expect 5. Explain each name without using real schedules or personal details.
