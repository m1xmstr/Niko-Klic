# Episode 53: Does Our Counter Really Work? Test It!

*Companion guide prepared; video release is pending.*

**Learning goal:** A test compares what happened with what we expected; several passing examples help but cannot prove every case.

**Prerequisites:** [Episode 46](./46.md), [Episode 48](./48.md).

## Try the real Python

Run this in a local Python 3 environment with a trusted grown-up. The terminal displays the output; the code does not move story props.

```python
stars = 2
result = stars + 1
print(result)
print(result == 3)
```

Expected terminal output:

```text
3
True
```

## Change one thing

Predict the result before running this fresh example.

```python
stars = 9
result = stars + 1
print(result)
print(result == 10)
```

Expected terminal output:

```text
10
True
```

## Try it together

Try starts zero, two and nine, expecting one, three and ten; change +1 to +2 and catch the mismatch. Write the predicted output on paper first, run with a grown-up, and compare. Use fictional names and practice values.

## Read the important line

`=` stores a value. `==` compares two values and produces `True` or `False`. Our expectation is that adding one to two gives three. One passing case does not prove every case works: also try zero and nine, expecting one and ten. Change the increment to `+ 2` to see a mismatch, then restore `+ 1`.
