# Can You Fix Klic's Route?

[Video](https://youtube.com/shorts/R5DSucUHPEU) — scheduled for November 16, 2026 at 3 PM America/Chicago. Public playback verification waits for release.

Klic wants to reach a star. The computer follows the given steps, but one turn in the plan is wrong. Predict, trace the route, and repair just that turn.

## Play together without a computer

Draw a four-by-four grid. Count columns from left to right and rows from top to bottom, starting at zero. Put a counter at column 0, row 2, facing right. Put a star at column 2, row 3.

Read aloud: "Forward two, turn left, forward one." Trace it together. Then reset the counter and change only LEFT to RIGHT. A turn changes which way the counter faces; it does not move it to a new square.

Swap roles: one person writes a route, the other follows it exactly. Check the plan kindly if it misses the goal.

## What actually ran

Independent Python processes executed a bounded grid simulator. The start, goal, forward distances, and coordinate rules stayed fixed.

| Case | Recorded positions | Result |
| --- | --- | --- |
| LEFT | (0,2), (1,2), (2,2), (2,1) | EMPTY TILE |
| Change only to RIGHT | (0,2), (1,2), (2,2), (2,3) | STAR |
| Fresh LEFT replay | (0,2), (1,2), (2,2), (2,1) | EMPTY TILE |

This is a simulation, not a physical robot. The animation follows recorded positions after each prediction pause. Changing the turn solves this particular route; a different start or goal can need a different plan.

## Runnable example

With a grown-up, save as `route.py` in a practice folder and run `python3 route.py`. It writes no files and makes no network requests. The simulator raises an error if a move leaves the grid.

```python
"""Pure bounded grid simulation. x increases right, y increases down."""
def simulate(turn):
 x,y=0,2;direction=0;path=[(x,y)];vectors=[(1,0),(0,1),(-1,0),(0,-1)]
 for count in [2,1]:
  for _ in range(count):
   dx,dy=vectors[direction];x+=dx;y+=dy
   if not (0<=x<4 and 0<=y<4):raise ValueError('outside grid')
   path.append((x,y))
  if count==2:direction=(direction+(1 if turn=='RIGHT' else -1))%4
 return {'turn':turn,'path':path,'finish':[x,y],'goal':[2,3],'result':'STAR' if (x,y)==(2,3) else 'EMPTY TILE'}

for turn in ["LEFT", "RIGHT", "LEFT"]:
    print(simulate(turn))
```

The three printed results end in EMPTY TILE, STAR, and EMPTY TILE. Compare both the result and the full path.
