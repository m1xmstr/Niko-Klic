# Episode 75: Pairs Plus a Spare! Python Functions Work Together

Video in preparation; not uploaded or scheduled. These Python examples have been executed locally and do not imply media approval or release.

**Learning goal:** Reuse a returned value by calling a helper function from another function.

**Prerequisites:** [Episode 51](./51.md), [Episode 64](./64.md).

## Run real Python

With a trusted grown-up, use a local Python 3 environment. Predict the terminal output before running the full example. No account or private information is needed.

```python
def wheels(pairs):
    return pairs * 2
def with_spare(pairs):
    return wheels(pairs) + 1
print(with_spare(2))
```

Expected output:

```text
5
```

with_spare calls wheels first, then adds one to the returned number. Two pairs become four wheels, then one spare makes five.

## Change one thing

Run this fresh example separately:

    return pairs * 2
