**Learning goal:** Pair corresponding items from two lists using zip.

## Working Python

With a trusted grown-up, run this complete example in a local Python3 environment. Use fictional values only.

```python
colors = ["red", "blue"]
shapes = ["star", "moon"]
for color, shape in zip(colors, shapes):
    print(color, shape)
```

Expected terminal output:

```text
red star
blue moon
```

zip defaults to stopping at the shortest input. Pairing is positional and does not search by meaning; no missing value is invented.

## Change one thing

```python
colors = ["red", "blue"]
shapes = ["star"]
for color, shape in zip(colors, shapes):
    print(color, shape)
```

Expected output:

```text
red star
```

## Story and practice

Nico holds a red paper strip beside a star-shaped stencil, presses them together on a craft mat, then lifts an unmatched blue strip. Klic brings a moon stencil, aligns its edge beside the blue strip, then places the moon stencil in a storage tray. Props illustrate the idea; print displays terminal text and does not control hardware.

With a grown-up, restore moon and check the two pairs. Then give shapes a third item and confirm only two pairs appear because colors has two items.

**Ask:** Why does blue disappear from the changed output?

**Answer:** The shorter shapes list has no second item, so default zip stops after one pair.
