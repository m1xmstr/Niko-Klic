# Episode 118: Find the Largest! Python max

Supplemental guide prepared; video release deferred while the curriculum expands to other technology subjects.

**Learning goal:** Find the largest value in a nonempty numeric list.

**Prerequisites:** [Episode 54](54.md), [Episode 48](48.md), [Episode 88](88.md).

## Working Python

With a trusted grown-up, run this complete example in a local Python3 environment. Use fictional values only.

```python
heights = [4, 7, 5]
tallest = max(heights)
print(tallest)
```

Expected terminal output:

```text
7
```

max returns the largest value, not an index, and does not modify the list. max([]) raises ValueError unless an explicit default is supplied.

## Change one thing

```python
heights = [4, 7, 9]
tallest = max(heights)
print(tallest)
```

Expected output:

```text
9
```

## Story and practice

Nico steadies a small tower model, holds a straight comparison bar above it, then raises a taller model onto a separate base. Klic brings a short measuring stick, compares the models at their tops, then lowers the stick carefully. Props illustrate the idea; print displays terminal text and does not control hardware.

With a grown-up, run max([7,7,4]) and predict 7. Then try max([]), read ValueError, and discuss checking for an empty list first as in lesson88.

**Ask:** Does max give the position?

**Answer:** No. It returns the largest value, and an empty input requires handling.
