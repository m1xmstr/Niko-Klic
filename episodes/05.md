# Episode 5: What’s a String?

[Watch Episode 5](https://www.youtube.com/shorts/PX3T7u5fzBQ)

**Concept:** Strings  
**Learning goal:** Identify a string as text represented in code.

Five letter tiles assemble into HELLO while the code displays the quoted string "HELLO".

## Learning path

After following sequences; introduces a text value before more data types.

## Try it together

Arrange paper letters to make a short greeting. An adult can write it inside quotation marks.

## Check understanding

**Ask:** What does the string contain?

**Answer:** The text HELLO.

## For grown-ups

Colored blocks are simplified pseudocode. Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed for these activities.
