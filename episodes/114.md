## Working Python

With a trusted grown-up, run this complete example in a local Python3 environment. Use fictional values only.

```python
for marker in range(0, 7, 2):
    print(marker)
```

Expected terminal output:

```text
0
2
4
6
```

range(0, 7, 2) yields 0, 2, 4, 6. Stop is excluded; step zero raises ValueError. These values are terminal text, not robot movement.

## Change one thing

```python
for marker in range(0, 7, 3):
    print(marker)
```

Expected output:

```text
0
3
6
```

## Story and practice

Crouch to place an orange stepping marker, stand to measure spacing, then slide the next marker farther outward. Carry a teal marker, lower it with both hands, and lean sideways to check the spacing. Props illustrate the idea; print displays terminal text and does not control hardware.

With a grown-up, change step to 4 and predict 0 then 4 on separate lines. Try step 0 and read ValueError. Use a pretend stepping course, not real hardware.

**Ask:** Why is seven excluded?

**Answer:** range stops before its stop argument; the step determines which earlier integers appear.
