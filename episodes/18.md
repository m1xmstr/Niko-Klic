# Episode 18: Words vs. Numbers

Prepared; not yet publicly released.

**Concept:** data types  
**Learning goal:** Distinguish a numeric value from a text character.

A numeric 2 becomes 3 when adding 1 while the quoted text "2" remains unchanged.

## Learning path

After Episodes 5 strings and 6 variables.

## Try it together

Write 2 and quoted "2" on cards; label number and text.

## Check understanding

**Ask:** Which value can we add one to in this example?

**Answer:** The number 2; the quoted text is a string.

## For grown-ups

Colored blocks are simplified pseudocode. Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed for these activities.
