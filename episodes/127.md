# Episode 127 — No Peeking! Test the Machine Learning Model

**Track:** Machine learning. **Prerequisite:** [122 — training examples and labels](122.md).

## Learning goal
Keep training and test examples separate. Record predictions before revealing test answers, then report what actually happened.

## Story
In the toy-animal sorting yard, Nico closes a covered test-label tray. Klic fixes a prediction card in its clip before Nico reveals the answer. The second card changes the input and exposes a mistake. The illustrated props show recorded model results; they do not control live hardware.

## Exact demonstration
The four training cards have arbitrary fictional ear-length units: CAT 1 and 3; RABBIT 7 and 9. The model learns the class averages, CAT 2 and RABBIT 8. It predicts whichever average is nearer. These numbers are not real animal biology.

| Held-out card | Input | Fixed prediction | Hidden label | Result |
| --- | --- | --- | --- | --- |
| test1 | 8 | RABBIT | RABBIT | Correct |
| test2 (changed input) | 4 | CAT | RABBIT | Incorrect |

Result: **1 of 2 correct**. Two fictional cases cannot establish real animal-identification accuracy. The model remains unchanged during both tests. Do not use test answers to train or tune this model; doing so would make these examples unsuitable for an independent test.

## Run with a grown-up
Save the following as `classifier.py` in a practice folder. Run `python3 classifier.py`. It uses only Python's standard library (verified with Python 3.14.6), fits a nearest-centroid model, saves and reopens it, saves both predictions before reading held-out labels, then scores them. It creates and removes its own temporary fixture. It prints terminal text, not paper.

```python
"""Fictional toy cards: fit once, predict without labels, then score."""
import json, hashlib, tempfile
from pathlib import Path
from statistics import mean
training = [
    {'id': 'train1', 'ear': 1, 'label': 'CAT'},
    {'id': 'train2', 'ear': 3, 'label': 'CAT'},
    {'id': 'train3', 'ear': 7, 'label': 'RABBIT'},
    {'id': 'train4', 'ear': 9, 'label': 'RABBIT'},
]
test_features = [{'id': 'test1', 'ear': 8}, {'id': 'test2', 'ear': 4}]
test_labels = {'test1': 'RABBIT', 'test2': 'RABBIT'}
assert {x['id'] for x in training}.isdisjoint(x['id'] for x in test_features)
with tempfile.TemporaryDirectory(prefix='nico-klic127-') as folder:
    root = Path(folder)
    (root/'training.json').write_text(json.dumps(training))
    (root/'test-features.json').write_text(json.dumps(test_features))
    (root/'held-out-labels.json').write_text(json.dumps(test_labels))
    train = json.loads((root/'training.json').read_text())
    model = {label: mean(x['ear'] for x in train if x['label'] == label)
             for label in sorted({x['label'] for x in train})}
    (root/'model.json').write_text(json.dumps(model, sort_keys=True))
    model_hash = hashlib.sha256((root/'model.json').read_bytes()).hexdigest()
    model = json.loads((root/'model.json').read_text())
    features = json.loads((root/'test-features.json').read_text())
    predictions = [dict(x, prediction=min(model, key=lambda k: abs(x['ear']-model[k])))
                   for x in features]
    # Commit both predictions BEFORE loading the held-out labels for scoring.
    (root/'predictions.json').write_text(json.dumps(predictions))
    prediction_hash = hashlib.sha256((root/'predictions.json').read_bytes()).hexdigest()
    labels = json.loads((root/'held-out-labels.json').read_text())
    results = [dict(x, label=labels[x['id']], correct=x['prediction']==labels[x['id']])
               for x in predictions]
    assert model_hash == hashlib.sha256((root/'model.json').read_bytes()).hexdigest()
    assert prediction_hash == hashlib.sha256((root/'predictions.json').read_bytes()).hexdigest()
    proof = dict(training=training, test_features=features, model=model, model_hash=model_hash,
                 prediction_hash=prediction_hash, predictions_saved_before_label_read=True,
                 model_unchanged=True, ids_disjoint=True, results=results,
                 correct=sum(x['correct'] for x in results), total=len(results),
                 scope='Two fictional held-out examples; not real animal accuracy')
assert not root.exists()
proof['temporary_fixture_removed'] = True
print(json.dumps(proof, indent=2))

```

The JSON output includes `model: {"CAT": 2, "RABBIT": 8}`, `ids_disjoint: true`, `predictions_saved_before_label_read: true`, `model_unchanged: true`, the two rows above, `correct: 1`, `total: 2`, and `temporary_fixture_removed: true`. All training and test data are explicitly initialized in the code. The label fixture exists for evaluation, but no test label enters fitting or prediction.

## Predict and check
Pause before uncovering the first label: which learned average is nearer to 8? Reveal RABBIT. For the changed input 4, predict CAT, then reveal that this fictional card is labeled RABBIT. Keep the mismatch in the result instead of changing the answer afterward.

## Grown-up activity
Make four labeled training cards and two separate test cards using the fictional numbers above. A grown-up covers the test labels before the child fits the two averages. Write both predictions on paper first, then uncover labels and count matches. No account, personal data, or real animals are needed.

## Questions and answers
- **Why cover the test labels?** The answers must not influence training or predictions.
- **Does a prediction become true because it sounds confident?** No. Compare it with the known label.
- **What changed between the two tests?** The input changed from 8 to 4; the model stayed fixed.
- **Did one correct answer prove this model identifies animals?** No. These are only two fictional cards.
- **Can we improve the model using these answers and still call this an untouched test?** No. A later independent evaluation needs fresh held-out examples.

**Recap:** Train, predict on separate examples, reveal, and check.
