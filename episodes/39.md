# Episode 39: Will Klic's Drawing Disappear? Save It

[Watch Episode 39](https://www.youtube.com/shorts/0pMLrTeac7E)

**Concept:** saving  
**Learning goal:** Save your work so you can open it later.

Saving keeps Nico and Klic’s drawing ready to open after the app closes. Watch them save, close, and reopen the star.

## Learning path

Earlier lessons: 17. Revisit these ideas before trying this activity.

## Story code

```text
DRAW > SAVE > CLOSE > OPEN
```

These are simplified pseudocode instructions.

## Try it together

Draw a star, put it in a folder labeled saved, close the folder, then reopen it.

## Check understanding

**Ask:** Why does Klic save before closing?

**Answer:** So the saved drawing can be opened later.

## For grown-ups

Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed.
