# Episode 39: Will My Drawing Stay? Discover Storage

Prepared; not yet publicly released.

**Concept:** storage  
**Learning goal:** Saving stores work so we can open it later.

Klic wants his drawing to be there when he comes back. Saving stores work so we can open it later.

## Learning path

Earlier lessons: 17. Revisit these ideas before trying this activity.

## Try it together

Draw a star, put it in a folder labeled saved, close the folder, then reopen it.

## Check understanding

**Ask:** Why does Klic save before closing?

**Answer:** So the saved drawing can be opened later.

## For grown-ups

Colored blocks are simplified pseudocode. Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed for these activities.
