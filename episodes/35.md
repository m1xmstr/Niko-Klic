# Episode 35: Three Clicks, Three Stars? Repeated Events

[Watch Episode 35](https://www.youtube.com/shorts/5EHdW7Bfpac)

**Concept:** repeated events  
**Learning goal:** Repeated events can run the same code again.

Repeated events make Klic’s star dispenser run again: each click creates exactly one star for Nico to catch.

## Learning path

Earlier lessons: 33. Revisit these ideas before trying this activity.

## Story code

```text
ON EACH CLICK: >     MAKE ONE STAR
```

These are simplified pseudocode instructions.

## Try it together

Start with zero paper stars. Add exactly one for each pretend click.

## Check understanding

**Ask:** How many stars do three clicks add?

**Answer:** Three stars, one per click.

## For grown-ups

Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed.
