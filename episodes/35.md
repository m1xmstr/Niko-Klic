# Episode 35: Three Clicks, How Many Stars? Repeated Events

Prepared; not yet publicly released.

**Concept:** repeated events  
**Learning goal:** Each click can trigger an action. Count the events.

Klic clicks a sticker button three times and three stickers appear. Each click can trigger an action. Count the events.

## Learning path

Earlier lessons: 33. Revisit these ideas before trying this activity.

## Try it together

Start with zero paper stars. Add exactly one for each pretend click.

## Check understanding

**Ask:** How many stars do three clicks add?

**Answer:** Three stars, one per click.

## For grown-ups

Colored blocks are simplified pseudocode. Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed for these activities.
