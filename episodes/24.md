# Episode 24: Don’t Share That!

Prepared; not yet publicly released.

**Concept:** personal information  
**Learning goal:** Recognize that a home address is personal information and pause before sharing it.

A fictional game asks for a home address. Klic pauses, keeps the pretend envelope closed, and chooses to ask a trusted grown-up.

## Learning path

Episodes 12 (permission) and 16 (keeping passwords private).

## Try it together

Use an empty paper envelope and a pretend game request. Practice saying: Pause. Keep details private. Ask a trusted grown-up. Do not write a real address.

## Check understanding

**Ask:** What should Klic do when the game asks for a home address?

**Answer:** Do not send it. Pause and ask a trusted grown-up for help.

## For grown-ups

Colored blocks are simplified pseudocode. Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed for these activities.
