# Episode 27: Call the Function!

Prepared; not yet publicly released.

**Concept:** function calls  
**Learning goal:** Distinguish defining a function from calling it to run its steps.

Klic has a WAVE definition, but remains still. Nico calls WAVE(), and the visible raise-then-sway demonstration runs.

## Learning path

Episodes 8 (functions) and 19 (reusing steps).

## Try it together

Write WAVE: raise hand, then sway hand. First only read the definition. When a grown-up says call WAVE, perform the steps. Defining alone does not run this example.

## Check understanding

**Ask:** What starts the steps in WAVE?

**Answer:** Calling WAVE() starts its defined steps.

## For grown-ups

Colored blocks are simplified pseudocode. Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed for these activities.
