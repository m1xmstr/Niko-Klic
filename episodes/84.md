# Episode 84: Where Did the Old Number Go? Trace Python Variables

Video in preparation; no native schedule yet.

**Learning goal:** Track a variable before and after reassignment, then trace a changed starting value.

**Prerequisites:** [Lesson 46](./46.md), [Lesson 53](./53.md), [Lesson 83](./83.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
total = 2
total = total + 3
print(total)
```

Expected terminal output:

```text
5
```

Python evaluates total + 3 using the old value, then assigns that result back to total. The equals sign assigns; it is not an equality comparison.

## Change one input

```python
total = 4
total = total + 3
print(total)
```

Expected terminal output:

```text
7
```

## What the story shows

Python displays the current variable value. The board path and cart illustrate following steps, and are handled physically by the characters.

## Try it together

With a grown-up, write three rows on paper for the program. Record total after each line, then run it in a local Python editor. Change the starting value from two to four and predict seven. Try starting at zero and predict three. Use pretend numbers, not private data.
