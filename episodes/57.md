# Episode 57: How Many Fit? Python len

[Watch Episode 57](https://youtube.com/shorts/Xi1fThrhRiA)

**Learning goal:** len counts items rather than the final index

**Prerequisites:** [Episode 54](./54.md).

## Try the real Python

Run this in a local Python 3 environment with a trusted grown-up. The terminal displays the output; the code does not move story props.

```python
toys = ['ball', 'kite']
print(len(toys))
```

Expected terminal output:

```text
2
```

## Change one thing

Predict the result before running this fresh example.

```python
toys = ['ball', 'kite', 'car']
print(len(toys))
```

Expected terminal output:

```text
3
```
