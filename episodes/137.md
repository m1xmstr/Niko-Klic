## Reproduce safely

On a grown-up-approved Linux practice system, create a fresh empty directory and work only inside it. The recorded proof used the dedicated local Linux VM, removed the fixture and stopped the VM. No personal files were used.

```sh
mkdir forest cave tower
printf "star\n" > forest/star.txt
printf "moon\n" > cave/moon.txt
printf "start\n" > tower/start.txt
find . -name star.txt
# ./forest/star.txt
find . -name moon.txt
# ./cave/moon.txt
```

These commands search from the current folder and match exact names here. They print paths, not contents, and do not move the files. The star.txt and start.txt distinction is intentional. With a grown-up, change the target name and predict the matching path. Cleanup only the files/folders you created in this fresh practice area. Do not run deletion commands in a personal folder.
