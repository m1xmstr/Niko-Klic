# Episode 8: The Secret Function

[Watch Episode 8](https://www.youtube.com/shorts/P6LczhyNUh4)

**Concept:** Functions  
**Learning goal:** See how a named group of steps can be called to perform the group.

Klic demonstrates HOP and SPIN. Nico names the group DANCE, then calls DANCE() to run both again.

## Learning path

Builds on Episode 4 sequences; later explore parameters and return values.

## Try it together

Name a safe two-action routine HELLO: wave, then clap. Say HELLO to call the routine.

## Check understanding

**Ask:** What happens when we call DANCE()?

**Answer:** The grouped HOP and SPIN steps run in order.

## For grown-ups

Colored blocks are simplified pseudocode. Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed for these activities.
