# Which Duck Gets the Crown?

Make a carnival pond with three slips of paper. Write **0**, **1**, and **2** on them for the docks. Put a Star duck at dock 0, a Moon duck at dock 1, and a Leaf duck at dock 2. Three toys or drawings work just as well.

Nico’s picker says **1**. Point to the duck you think should wear the paper crown. Now lift the crown and let Klic swap Moon and Leaf. Leave the numbered docks where they are. The picker still says **1**. Who gets the crown this time?

## Run the picker

```python
ducks = ["Star", "Moon", "Leaf"]
print(ducks[1])

ducks[1], ducks[2] = ducks[2], ducks[1]
print(ducks[1])
```

The first pick is **Moon**. The second is **Leaf**. A Python list counts its positions from zero, so `ducks[1]` picks whichever duck is in the second spot.
