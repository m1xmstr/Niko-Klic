## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
from urllib.parse import urlsplit
link = "https://example.com/map"
parts = urlsplit(link)
print(parts.scheme)
print(parts.scheme == "https")
```

Expected terminal output:

```text
https
True
```

parts.scheme reads the scheme label. Comparing that string with https only checks the parsed text; it does not connect to the server, verify a certificate, or establish that a site is trustworthy.

## Change one input

```python
from urllib.parse import urlsplit
link = "http://example.com/map"
parts = urlsplit(link)
print(parts.scheme)
print(parts.scheme == "https")
```

Expected terminal output:

```text
http
False
```

## What the story shows

The code only parses a fictional URL. HTTPS names a protocol, but this string check is not a live connection check or a safety verdict. The label/cape analogy illustrates reading a label without proving contents.

## Try it together

With a grown-up, compare the provided https and http sample strings without opening either link. Predict https/True then http/False. Explain why printing True is not proof that a website is safe. Never enter account links or private data.
