## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
text = "red,blue"
colors = text.split(",")
print(colors)
print(len(colors))
```

Expected terminal output:

```text
['red', 'blue']
2
```

split(",") separates at commas and returns a list. It does not remove spaces from items or implement full CSV parsing.

## Change one input

```python
text = "red,blue,green"
colors = text.split(",")
print(colors)
print(len(colors))
```

Expected terminal output:

```text
['red', 'blue', 'green']
3
```

## What the story shows

Exact Python strings and outputs. Physical props illustrate the concept; print displays terminal text only.
