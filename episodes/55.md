# Episode 55: Which Toy Is Zero? Python Indexing

[Watch Episode 55](https://youtube.com/shorts/oUprGOD9_5g)

**Learning goal:** Select one item from a Python list using its zero-based position.

**Prerequisite:** [Episode 54: Lists](./54.md).

## Try the real Python

With a trusted grown-up, run this in a local Python 3 environment. `print` displays text in the terminal; it does not move a toy.

```python
toys = ['ball', 'kite']
print(toys[0])
```

Expected terminal output:

```text
ball
```

The brackets after `toys` select an item. Index `0` selects the **first** item, `ball`. Zero is a position here; it does not mean the list is empty. The quotes are part of the source code, but `print` displays the selected string without those quotes.

## Change one thing

Change the index from `0` to `1`. Predict the result, then run this fresh example:

```python
toys = ['ball', 'kite']
print(toys[1])
```

Expected terminal output:

```text
kite
```

Index `1` selects the **second** item. Selecting an item does not remove it or change the list.

## Check that the list stayed the same

```python
toys = ['ball', 'kite']
print(toys[0])
print(toys)
```

Expected terminal output:

```text
ball
['ball', 'kite']
```

For this two-item list, `0` and `1` are the valid nonnegative indexes. Index `2` would ask for a third item that does not exist. Python also supports negative indexes, which we can explore in a later lesson.

## Try it together

Draw two boxes in a row on paper. Write **ball** and **kite** inside. Label their positions **0** and **1** underneath. Ask a grown-up to name an index; touch that box and say its value. Leave both items in place. Swap the two words, then predict what `toys[0]` would select from the changed list.

A list's position is useful when a program needs one item from an ordered collection. The item's position and the item's value are different things.
