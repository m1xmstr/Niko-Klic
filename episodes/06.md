# Episode 6: The Mystery Number

[Watch Episode 6](https://www.youtube.com/shorts/nG6B96IKGEo)

**Concept:** Variables  
**Learning goal:** Track a named value as it changes while the name stays the same.

SCORE starts at zero and changes to one and two as Klic collects two stars.

## Learning path

Builds on counting and Episode 2; later compare numbers with Episode 5 text.

## Try it together

Label a paper box SCORE. Put in number cards 0, 1, then 2 as you collect two toy stars.

## Check understanding

**Ask:** Does the name SCORE change?

**Answer:** No. The value changes from 0 to 1 to 2.
