# Episode 104: Too Much Space! Python strip

Video in preparation; no native schedule yet.

**Learning goal:** Trim whitespace from both ends of a string.

**Prerequisites:** [Lesson 44](./44.md), [Lesson 47](./47.md), [Lesson 54](./54.md), [Lesson 57](./57.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
label = "  Star  "
clean = label.strip()
print(clean)
print(len(clean))
```

Expected terminal output:

```text
Star
4
```

clean = label.strip() returns a new string; it does not alter label. It removes leading and trailing whitespace, not internal spaces.

## Change one input

```python
label = "  Moon  "
clean = label.strip()
```

Expected terminal output:
