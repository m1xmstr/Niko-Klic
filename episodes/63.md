# Episode 63 — Three Doors, One Choice! Python `elif`

**Video release pending.** These working examples accompany the upcoming lesson.

Python `elif` checks another condition when an earlier `if` condition did not match. An `if`/`elif`/`else` chain chooses its first matching branch.

Learning objective: trace a three-way choice in order, predict its printed message, then change one value and compare the result.

Prerequisites: [if/else in Episode 49](49.md) and [Boolean checks in Episode 62](62.md).

## Try yellow

```python
color = 'yellow'
if color == 'green':
    print('GO')
elif color == 'yellow':
    print('SLOW')
else:
    print('WAIT')
```

Expected terminal output:

```text
SLOW
```

1. `color` contains the text `'yellow'`.
2. `color == 'green'` is false, so Python skips `print('GO')`.
3. `elif` checks the next condition. Yellow matches yellow, so Python prints `SLOW`.
4. The chain is finished. `else` does not run when an earlier branch matched.

`==` compares two values; `=` assigns a value to a variable. Keep quotation marks around text, colons after the conditions and `else`, and four spaces before each `print` line. `elif` is one Python keyword, not two separate words.

## Change only the color

Predict the message, then run this version:

```python
color = 'red'
if color == 'green':
    print('GO')
elif color == 'yellow':
    print('SLOW')
else:
    print('WAIT')
```

Expected terminal output:

```text
WAIT
```

Red matches neither green nor yellow. `else` handles the remaining case. It has no condition of its own.

| Value of `color` | Printed message |
| --- | --- |
| `'green'` | `GO` |
| `'yellow'` | `SLOW` |
| `'red'` | `WAIT` |
| `'blue'` | `WAIT` |

Only one branch runs in this chain. Separate, independent `if` statements can behave differently; this lesson uses a connected `if`/`elif`/`else` chain.

## Try it with a grown-up

Make green, yellow, red and blue paper cards. Place three message cards on a table: GO, SLOW and WAIT. For each color, read the checks in order and choose only the first matching branch. With a grown-up, change the Python value and check the printed message.

Question: Does `'blue'` print both `SLOW` and `WAIT`?

Answer: No. Blue does not match green or yellow, so only the `else` branch prints `WAIT`.
