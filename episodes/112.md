## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
name = "draft_star.txt"
print(name.startswith("draft_"))
```

Expected terminal output:

```text
True
```

str.startswith tests the exact case-sensitive prefix. It is not a file existence, content safety, identity, or authorization check.

## Change one input

```python
name = "final_star.txt"
print(name.startswith("draft_"))
```

Expected terminal output:

```text
False
```

## What the story shows

Exact Python strings and outputs. Physical props illustrate the concept; print displays terminal text only.
