**Learning goal:** Join a list of strings with a chosen separator.

**Prerequisites:** [Lesson 44](./44.md), [Lesson 47](./47.md), [Lesson 54](./54.md), [Lesson 57](./57.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
parts = ["red", "blue"]
label = " / ".join(parts)
print(label)
```

Expected terminal output:

```text
red / blue
```

" / ".join(parts) inserts the separator between string items only. A nonempty list of n strings has n-1 separators.

## Change one input

```python
parts = ["red", "blue", "green"]
label = " / ".join(parts)
print(label)
```

Expected terminal output:

```text
red / blue / green
```
