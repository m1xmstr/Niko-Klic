# Episode 49: Go or Wait? Python Chooses With If and Else

[Watch Episode 49](https://youtube.com/shorts/4HZLSwSa-Qk)

**Learning goal:** Only the matching branch runs. Indentation groups the lines inside each branch.

**Prerequisites:** [Episode 28](./28.md), [Episode 48](./48.md).

## Try the real Python

Run this in a local Python 3 environment with a trusted grown-up. The terminal displays the output; the code does not move story props.

```python
stars = 3
if stars >= 3:
    print("GO")
else:
    print("WAIT")
```

Expected terminal output:

```text
GO
```

## Change one thing

## Try it together

Trace the True path and False path on paper, then run both values. Write the predicted output on paper first, run with a grown-up, and compare. Use fictional names and practice values.

## Read the important line

The colon after `if` begins its branch. The four spaces before `print` show which instruction belongs inside it. When `stars >= 3` is `True`, Python prints `GO`. Otherwise, `else` prints `WAIT`. In this example, exactly one branch runs. Keep both colons and the spaces when copying.
