# Episode 88: No Brush in the List! Python Empty Checks

Natively scheduled for **2026-10-13T10:40:00-05:00 (America/Chicago)**. Public playback and manual English captions will be checked after release.

**Learning goal:** Use a list truth check to avoid reading index zero from an empty list.

**Prerequisites:** [Lesson 37](./37.md), [Lesson 38](./38.md), [Lesson 67](./67.md), [Lesson 87](./87.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
tools = []
if tools:
    print(tools[0])
else:
    print('empty')
```

Expected terminal output:

```text
empty
```

An empty list is false in an if condition. A nonempty list is true. The index-zero read only runs when an item exists.

## Change one input

```python
tools = ['brush']
if tools:
    print(tools[0])
else:
    print('empty')
```

Expected terminal output:

```text
brush
```
