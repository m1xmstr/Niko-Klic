# Episode 95: What Does the Ending Tell Us? Python File Suffix

Video in preparation; no native schedule yet.

**Learning goal:** Read a filename’s final suffix and compare it with .txt, while distinguishing its name from actual content.

**Prerequisites:** [Lesson 54](./54.md), [Lesson 62](./62.md), [Lesson 93](./93.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
from pathlib import Path
p = Path("story.txt")
print(p.suffix)
print(p.suffix == ".txt")
```

Expected terminal output:

```text
.txt
True
```

p.suffix returns the final dot-suffix of the filename. The comparison checks only the name. Constructing this Path does not read a file or prove its format, contents or safety.

## Change one input

```python
from pathlib import Path
p = Path("story.png")
print(p.suffix)
print(p.suffix == ".txt")
```

Expected terminal output:

```text
.png
False
```

## What the story shows

The program examines a pretend filename only. It does not open or rename a file. A filename ending is a label, not a guarantee about content or safety; ask a grown-up before opening unfamiliar files.

## Try it together

With a grown-up, run story.txt and story.png. Predict .txt and True, then .png and False. Change the name to story with no dot: the first printed line is empty and the comparison is False. Use made-up filenames, not downloaded files.
