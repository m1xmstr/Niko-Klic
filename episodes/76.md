## Run real Python

With a trusted grown-up, use a local Python 3 environment. Predict the terminal output before running the full example. No account or private information is needed.

```python
import math
badges = 5
sleeves = math.ceil(badges / 2)
print(sleeves)
```

Expected output:

```text
3
```

math.ceil(badges / 2) rounds 2.5 up to 3, or 3.5 up to 4. import math makes this standard-library module available.

## Change one thing

Run this fresh example separately:

```python
import math
badges = 7
sleeves = math.ceil(badges / 2)
print(sleeves)
```
