**Learning goal:** Choose a file by its name, open it for reading and display its stored text without replacing the contents.

## Prepare the text files first

Save these exact contents in the same new practice folder as `main.py`, with no trailing newline.

### `moon.txt`

```text
Moon
```

### `sun.txt`

```text
Sun
```

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
filename = 'moon.txt'
with open(filename) as note:
    text = note.read()
print(text)
```

Expected terminal output:

```text
Moon
```

open(filename) uses read mode by default. note.read returns text; print displays that text after the with block closes the file.

## Change one input

```python
filename = 'sun.txt'
with open(filename) as note:

```

Expected terminal output:
