# Episode 41: My Drawing Is Gone! Try Recovery

Prepared; not yet publicly released.

**Concept:** recovery  
**Learning goal:** A backup can help restore lost work. Check the restored copy.

Klic accidentally loses a pretend drawing but has a backup. A backup can help restore lost work. Check the restored copy.

## Learning path

Earlier lessons: 17, 39. Revisit these ideas before trying this activity.

## Try it together

Make two matching paper drawings. Keep one as a backup, hide the working drawing, then use the backup and compare.

## Check understanding

**Ask:** What makes recovery possible in this example?

**Answer:** A backup copy was saved before the drawing was lost.

## For grown-ups

Colored blocks are simplified pseudocode. Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed for these activities.
