# Episode 69: Rain or No Rain? Python not Flips the Answer

Video release pending. This guide contains prepared Python examples; it is not a claim that the video is published.

**Learning goal:** Turn True into False and False into True using not.

**Prerequisites:** [Episode48](./48.md), [Episode62](./62.md).

## Run real Python

With a trusted grown-up, use a local Python 3 environment. First predict the terminal output. Python prints text; the story props are moved by the characters. No account or personal information is needed.

```python
raining = True
print(not raining)
```

Expected terminal output:

```text
False
```

not reverses this Boolean answer. It does not change the value stored in raining.

## Change one thing

Run this fresh example separately and compare:

```python
raining = False
print(not raining)
```

Expected terminal output:

```text
True
```

## What the story shows

The variable is a fictional flag, not a weather sensor. Python only prints the result; it neither checks real weather nor controls watering.

## Try it together

Choose a fictional Boolean flag for a toy game, predict not flag, change the flag and rerun. A grown-up can write the two possible results on paper, pause for your prediction, and help you compare with the terminal. Use only made-up practice values.

**Ask:** Does not change the value stored in raining?

**Answer:** No. It makes an opposite Boolean answer for this check.
