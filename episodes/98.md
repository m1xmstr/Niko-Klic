# Episode 98: Which Part Names the Website? Python URLs

Natively scheduled for **2026-10-15T10:20:00-05:00 (America/Chicago)**. Public playback and manual English captions will be checked after release.

**Learning goal:** Parse a known fictional URL and distinguish its hostname from its path.

**Prerequisites:** [Lesson 54](./54.md), [Lesson 77](./77.md), [Lesson 93](./93.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
from urllib.parse import urlsplit
link = "https://example.com/garden"
parts = urlsplit(link)
print(parts.hostname)
print(parts.path)
```

Expected terminal output:

```text
example.com
/garden
```

urlsplit separates URL components. parts.hostname names the host and parts.path contains the path beginning with a slash. This parses text without opening the website and does not validate a URL or prove safety.

## Change one input

```python
from urllib.parse import urlsplit
link = "https://example.com/pond"
parts = urlsplit(link)
print(parts.hostname)
print(parts.path)
```

Expected terminal output:

```text
example.com
/pond
```

The miniature map illustrates address parts. Python only parses the fictional example.com string; it does not contact a server, browse a site, or verify safety.
