# Episode 65 — The Numbers Are Mixed Up! Python `sorted`

**Video release pending.** These working examples accompany the upcoming lesson.

Python `sorted` makes a new list in order. It leaves the original list unchanged.

Learning objective: display an ordered copy of a number list, compare it with the original, and predict both outputs after changing the input.

Prerequisites: [lists in Episode 54](54.md), [indexing in Episode 55](55.md), and [displaying terminal text in Episode 44](44.md).

## Order a copy

```python
scores = [3, 1, 2]
print(sorted(scores))
print(scores)
```

Expected terminal output:

```text
[1, 2, 3]
[3, 1, 2]
```

1. `scores` stores the list in its original order: `3`, `1`, `2`.
2. `sorted(scores)` creates a **new list**, with these numbers from smallest to largest.
3. The first `print` displays that ordered copy.
4. The second `print` displays `scores` itself. Its original order remains `3`, `1`, `2`.

The two print lines do different jobs. Sorting the copy did not replace the original variable.

## Change the numbers

Predict both lines, then run:

```python
scores = [4, 2, 1]
print(sorted(scores))
print(scores)
```

Expected terminal output:

```text
[1, 2, 4]
[4, 2, 1]
```

The input changed to a new original list. Again, the first output is ordered; the second preserves the order written in `scores`.

## Keep the copy for later

```python
scores = [3, 1, 2]
ordered_scores = sorted(scores)
print(ordered_scores)
print(scores)
```

Expected terminal output:

```text
[1, 2, 3]
[3, 1, 2]
```

Now `ordered_scores` stores the new list. Use it when you want to compare numbers in order while keeping `scores` in its original order. For example, a game might keep scores in the order players took turns and make a separate ordered list to compare the numbers.
