# Episode 47: Did Python Add or Join? Strings vs Numbers

[Watch Episode 47](https://www.youtube.com/shorts/b-Z3MpOYP2M)

**Learning goal:** Quoted text joins with `+`; these unquoted numbers add.

## Learning path

Build on [Episode 5: strings](05.md), [Episode 44: Python print](44.md), and [Episode 46: variables](46.md).

## Run the code

```python
print("2" + "3")
print(2 + 3)
```

Terminal output:

```text
23
5
```

Quotation marks make `"2"` and `"3"` strings: pieces of text. The first `+` joins those strings in order. Without quotation marks, `2` and `3` are numbers, so `+` adds them. `print` shows each result on its own line.

## Change the inputs

Predict each line before running:

```python
print("1" + "4")
print(1 + 4)
```

Terminal output:

```text
14
5
```

The text changes to `14`; the number sum is still 5.
