## Run real Python

With a trusted grown-up, use a local Python 3 environment. First predict the terminal output. Python prints text; the story props are moved by the characters. No account or personal information is needed.

```python
# Use a made-up name, never private details.
nickname = 'StarBot'
print(nickname)
```

Expected terminal output:

```text
StarBot
```

A line beginning with # is a comment Python ignores. It explains why we chose a fictional nickname; the assignment and print run.

## Change one thing

Run this fresh example separately and compare:

```python
# Use a made-up name, never private details.
nickname = 'MoonBot'
print(nickname)
```

Expected terminal output:

```text
MoonBot
```

## What the story shows

This is a Python comment outside a quoted string. It is not a privacy control. Never put real secrets in source or comments; Python print writes terminal text only.
