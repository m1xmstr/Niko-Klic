# Episode 128 — Where Should We Go? LLM Prompts

**Track:** LLM. **Prerequisites:** [123 — tokens](123.md) and [126 — check an answer](126.md).

## Learning goal
Give a language model a goal, relevant fictional context and a reply format, then check what it actually returns. A clearer prompt can still get a wrong answer.

## Story
Nico unrolls a toy map in the map-making studio. Klic turns a direction dial as they compare a vague request with a request containing a start, destination and format. Then Nico changes the destination. The props illustrate recorded responses; they are not live navigation.

## Exact recorded demonstration
These three independent local requests used Ollama 0.16.3 with `llama3.2:3b` (model digest `a80c4f17acd55265feec403c7aef86be0c25983ab279d83f3bcd3abbcb5b8b72`). Options were temperature 0, seed 128 and maximum 80 generated tokens. Each request started a fresh conversation with the same system instruction: `Keep your answer under twenty words.` No real location or personal information was used.

The first response exceeded that word limit; even a simple constraint is not guaranteed. The model identifier is given for reproducibility, not as an endorsement. Outputs may differ with another model, version or environment.

### Request 1

**Prompt:**
```text
Give me directions.
```

**Exact response:**
```text
I'd be happy to help, but I need more information about what you're looking for directions on (e.g., a location, activity).
```

### Request 2

**Prompt:**
```text
Toy map: red hut -> bridge -> pond. Start at red hut. End at pond. Write only the three stops, separated by arrows.
```

**Exact response:**
```text
→ Red Hut → Bridge → Pond
```

### Request 3

**Prompt:**
```text
Toy map: red hut -> bridge -> pond. Start at red hut. End at bridge. Write only the stops you visit, separated by arrows.
```

**Exact response:**
```text
→ Red Hut → Bridge
```

## Predict and check
Before revealing response 2, predict the stops from the supplied map. The route is red hut, bridge, pond. Compare the actual reply with that route. For request 3, only the destination changes to bridge and the requested reply describes the visited stops: red hut, bridge. The leading arrow and capitalization are retained exactly in the recorded replies.

These successful toy examples do not establish navigation ability or general reliability. A real journey needs a trusted grown-up and an appropriate source; this lesson uses only a pretend map.

## Run with a grown-up
Optional local reproduction: a grown-up needs an already installed, running Ollama service and the `llama3.2:3b` model. This script does not install software, download models or call a paid service. Save it as `run_prompt_comparison.py`, then run `python3 run_prompt_comparison.py`. It uses Python’s standard library to make three independent requests to the local loopback API. Output is terminal text. The animation itself shows no Python code.

```python
"""Three independent fictional-map requests to an already installed local model."""
import json, urllib.request, hashlib
from pathlib import Path
MODEL = 'llama3.2:3b'
SYSTEM = 'Keep your answer under twenty words.'
PROMPTS = [
 'Give me directions.',
 'Toy map: red hut -> bridge -> pond. Start at red hut. End at pond. Write only the three stops, separated by arrows.',
 'Toy map: red hut -> bridge -> pond. Start at red hut. End at bridge. Write only the stops you visit, separated by arrows.'
]
OPTIONS = {'temperature': 0, 'seed': 128, 'num_predict': 80}
def request(path, data=None):
 body = None if data is None else json.dumps(data).encode()
 req = urllib.request.Request('http://127.0.0.1:11434' + path, data=body, headers={'Content-Type': 'application/json'})
 with urllib.request.urlopen(req, timeout=180) as response:
  return json.load(response)
proof = {'runtime': request('/api/version'), 'model': next(x for x in request('/api/tags')['models'] if x['name'] == MODEL), 'system': SYSTEM, 'options': OPTIONS, 'requests': []}
for prompt in PROMPTS:
 response = request('/api/chat', {'model': MODEL, 'messages': [{'role': 'system', 'content': SYSTEM}, {'role': 'user', 'content': prompt}], 'stream': False, 'options': OPTIONS, 'keep_alive': 0})
 proof['requests'].append({'prompt': prompt, 'response': response})
proof['source_sha256'] = hashlib.sha256(Path(__file__).read_bytes()).hexdigest()
proof['scope'] = 'Fictional toy map; three independent local requests. No real addresses, live navigation, remote services or paid model calls.'
print(json.dumps(proof, indent=2))
```

## Grown-up activity
Draw three pretend places joined in a line. Ask the child to name a start and destination and predict the stops. Add a reply format such as “stops separated by arrows.” Change the destination and compare the new route. This can be a paper role-play; no child account, online service or private addresses are needed.

## Questions and answers

- **What was missing from “Give me directions”?** A clear start, destination and context.
- **What did we add?** The toy map, a goal and a reply format.
- **Does clearer wording guarantee a correct reply?** No. Check it against the supplied map.
- **Why show the model’s exact words?** So we can distinguish what it returned from our explanation.
- **Why use a pretend map?** It supports the lesson without sharing anyone’s real location.

**Recap:** Name the job, give details, then check the reply.
