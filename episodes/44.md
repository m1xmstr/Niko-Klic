# Episode 44: Can One Python Line Fill Klic's Blank Sign?

Published October 8, 2026: [Watch Episode 44](https://www.youtube.com/shorts/qvIf6xWC_rQ).

**Concept:** Python instructions and text output
**Learning goal:** Run one Python instruction, identify its output, then change the quoted text and predict the new result.

Klic brings a blank welcome sign. Nico writes a real Python instruction. They compare the words on the screen before Klic manually turns his sign to match.

## Learning path

Revisit [Episode 5: strings](05.md) and [Episode 32: output](32.md). Next, Episode 45 will explore a missing quote and a syntax error; it is still planned.

## Run the code

```python
print("Hello, Klic!")
```

The terminal displays:

```text
Hello, Klic!
```

`print` displays text on the screen. The parentheses enclose what we give it, and the quote marks identify the text. The quote marks themselves are not displayed in this output. This instruction does not operate a paper printer or move a physical robot.

## Change one thing

Predict what changes when we replace `Hello` with `Welcome`:

```python
print("Welcome, Klic!")
```

Output:

```text
Welcome, Klic!
```

The instruction stays the same; the quoted text changes. Both exact snippets were executed locally and their outputs checked.
