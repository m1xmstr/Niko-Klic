# Episode 19: Klic’s Reusable Trick

Prepared; not yet publicly released.

**Concept:** reuse  
**Learning goal:** Reuse a named group of instructions without rewriting it.

One DANCE function definition is called twice, performing the same two steps.

## Learning path

After Episode 8 functions.

## Try it together

Name a wave-and-clap routine and call it twice.

## Check understanding

**Ask:** Did we rewrite the function for the second call?

**Answer:** No. We reused the same definition.

## For grown-ups

Colored blocks are simplified pseudocode. Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed for these activities.
