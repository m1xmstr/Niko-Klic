# Episode 3: If / Then!

[Watch Episode 3](https://www.youtube.com/shorts/yEZ-p6Z2pks)

**Concept:** Conditions  
**Learning goal:** Predict whether an action should run when a condition matches.

Klic waits at red, jumps at blue, and waits when the light turns red again.

## Learning path

Builds on following instructions; connects to Episode 7.

## Try it together

Use blue and red paper cards. Jump only when the blue card is shown, with room to move safely.

## Check understanding

**Ask:** What happens when the light is red?

**Answer:** The blue condition is false, so Klic waits.

## For grown-ups

Colored blocks are simplified pseudocode. Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed for these activities.
