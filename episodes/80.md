**Learning goal:** Recognize a zero divisor from the final error line, fix it, and rerun a small Python program.

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
boxes = 2
print(6 // boxes)
```

Expected terminal output:

```text
3
```

Double slash computes the whole-number quotient here. Division by zero raises ZeroDivisionError and stops this run. A positive boxes value lets it finish.

## Change one input

```python
boxes = 3
print(6 // boxes)
```

Expected terminal output:

```text
2
```

## What the story shows

Python displays the quotient in a terminal. Characters share physical cubes by hand; Python does not move them. Six is divisible by two and three.

## Try it together

With a grown-up and a local Python editor, save this two-line program in a new practice folder. Run with boxes set to two, then three. Try zero and read the last error line; change it back to two and rerun. No account or personal data is needed.

## Read the error

```python
boxes = 0
print(6 // boxes)
```

This run raises `ZeroDivisionError`. Read the final error line, fix the divisor, and rerun.
