# Episode 28: Will Klic Cross? A Branching Puzzle!

Scheduled for October 7, 2026 at 12:00 PM America/Chicago. Not yet publicly released.

**Concept:** branching

**Learning goal:** Use an IF / ELSE condition to choose exactly one action.

Klic stops at a closed toy bridge. Nico checks the condition: if the bridge is open, cross; otherwise, wait. When the sign changes to OPEN, Klic takes the cross branch.

## Learning path

[Episode 3: conditions](03.md) → [Episode 7: true or false](07.md) → this branching puzzle.

## Read the code

```text
IF OPEN:
    CROSS
ELSE:
    WAIT
```

The two branches are alternatives: one runs each time the condition is checked.

## Try it together

Make OPEN and CLOSED cards. With a grown-up, use a pretend bridge drawn on paper. Choose CROSS for OPEN and WAIT for CLOSED. Change the card and check again. Use a tabletop toy, not a real road or bridge.

## Check understanding

**Ask:** The sign is CLOSED. Which branch runs?

**Answer:** ELSE: WAIT. If the sign becomes OPEN, checking again chooses CROSS.

## For grown-ups

The blocks are simplified pseudocode. Ask your child to point to the selected branch before moving the toy. No account or paid tool is needed.
