# Where Is the Star File? Linux pwd and ls

Nico and Klic search a little treehouse model. A recorded Linux terminal tells them where the current folder is, what names are inside it, and how to enter a child folder. The model is an illustration; commands do not operate a physical house.

**Objective:** Read a current folder path, list its names, and enter one child folder without moving any files.

**Prerequisite:** Lesson 119, the introduction to Linux and operating systems. Work with a grown-up in a disposable Linux practice environment.

## Exact practice setup

The recording used fictional empty files in a dedicated local Linux VM: Fedora CoreOS 41, Linux 6.12.13, GNU coreutils 9.5. These are the recorded environment versions, not a recommendation to install an older operating system.

A grown-up created `/tmp/treehouse/art/star.txt` and `/tmp/treehouse/music/song.txt`, then started the shell in `/tmp/treehouse` with `LC_ALL=C`. Do not overwrite an existing folder. An adult can prepare a new practice fixture:

```sh
test ! -e /tmp/treehouse && mkdir -p /tmp/treehouse/art /tmp/treehouse/music && touch /tmp/treehouse/art/star.txt /tmp/treehouse/music/song.txt
cd /tmp/treehouse
export LC_ALL=C
```

Only continue if the setup succeeded. The recording's temporary fixture was removed afterwards; no personal files were used.

## First run

```sh
pwd
ls
```

Recorded output:

```text
/tmp/treehouse
art
music
```

`pwd` reports the current folder's path. `ls` lists names inside the current folder. In this fixture, `art` and `music` are directories. By default, `ls` omits names starting with a dot. Output may appear in columns in an interactive terminal; the recorded captured output uses one name per line.

## Predict, then change

What will the path end with after entering `art`? Pause before checking.

```sh
cd art
pwd
ls
```

Recorded output:

```text
/tmp/treehouse/art
star.txt
```

`cd art` changes the shell's current folder. It does not move `star.txt`. The file was already inside `art`. The exact path spells the temporary directory `tmp`; the narration pronounces it “temp.”

## Recall and activity

- Which command tells us where we are? **`pwd`.**
- Which command lists names here? **`ls`.**
- Did the star file move? **No. We changed the current folder.**
- With a grown-up, draw two folder rooms, choose a child folder in a separate practice environment, and compare `pwd` and `ls` before and after entering it. Keep any new observed results separate from the recorded example above.

Technical references: [GNU pwd](https://www.gnu.org/s/coreutils/manual/html_node/pwd-invocation.html), [GNU ls](https://www.gnu.org/s/coreutils/manual/html_node/ls-invocation.html), [Bash cd builtin](https://www.gnu.org/software/bash/manual/html_node/Bourne-Shell-Builtins.html).
