## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
text = "2.5"
length = float(text)
print(length + 1)
```

Expected terminal output:

```text
3.5
```

float(text) converts valid numeric text. Many decimal fractions are approximate; these half-unit examples are exact in binary floating point.

## Change one input

```python
text = "3.5"
length = float(text)
print(length + 1)
```

Expected terminal output:

```text
4.5
```
