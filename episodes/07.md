# Episode 7: True or False?

In production — watch link will be added after verified publication.

**Concept:** Booleans  
**Learning goal:** Recognize true and false as the two Boolean values.

HAS KEY? is false until Klic collects the key. It becomes true and the gate opens.

## Learning path

Builds directly on Episode 3 conditions.

## Try it together

Ask whether a toy has a paper key. Answer true or false, then give it the key and test again.

## Check understanding

**Ask:** What makes HAS KEY? true?

**Answer:** Klic having the key.

## For grown-ups

These short stories introduce a concept through visible action. Colored blocks are simplified pseudocode, not the syntax of every programming language. Pause, predict, and retell the sequence together. No account, personal information, passwords, or paid tool is needed for this activity.
