# Episode 7: True or False?

[Watch Episode 7](https://www.youtube.com/shorts/HsVstiyDFHM)

**Concept:** Booleans  
**Learning goal:** Recognize true and false as the two Boolean values.

HAS KEY? is false until Klic collects the key. It becomes true and the gate opens.

## Learning path

Builds directly on Episode 3 conditions.

## Try it together

Ask whether a toy has a paper key. Answer true or false, then give it the key and test again.

## Check understanding

**Ask:** What makes HAS KEY? true?

**Answer:** Klic having the key.

## For grown-ups

Colored blocks are simplified pseudocode. Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed for these activities.
