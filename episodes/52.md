# Episode 52: Where Did Our Python Program Go?

*Companion guide prepared; video release is pending.*

**Learning goal:** The editor saves instructions in a .py file; running print displays output and does not save the source file.

**Prerequisites:** [Episode 39](./39.md), [Episode 44](./44.md).

## Try the real Python

Run this in a local Python 3 environment with a trusted grown-up. The terminal displays the output; the code does not move story props.

```python
print("Hello again, Klic!")
```

Expected terminal output:

```text
Hello again, Klic!
```

## Change one thing

Predict the result before running this fresh example.

```python
print("Welcome back, Klic!")
```

Expected terminal output:

```text
Welcome back, Klic!
```

## Try it together

With a grown-up, save star_workshop/hello.py in a local practice folder, close, reopen and rerun. Change the greeting, save again and compare output; use no private data. Write the predicted output on paper first, run with a grown-up, and compare. Use fictional names and practice values.

## Read the important line

Save the written instructions in `hello.py`. Close and reopen that file before running it again. `print` displays terminal output; it does not save your source. For the changed example, edit the file, save again, and run that same file. Some editors auto-save; this exercise deliberately practices manual saving.
