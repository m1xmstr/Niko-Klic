## Reproduce safely

The illustrated rule is not displayed as runnable shell. This complete Python example reproduces the recorded votes:

```python
from collections import Counter
# Fictional numerical examples. No real people or images.
examples = [(0, "blue"), (1, "blue"), (2, "gold"),
            (10, "blue"), (11, "blue"), (12, "blue")]
def classify(x, rows):
    neighbors = sorted(rows, key=lambda row: abs(row[0] - x))[:3]
    label, votes = Counter(label for _, label in neighbors).most_common(1)[0]
    return label, votes, [label for _, label in neighbors]
for name, x in [("A", 1), ("B", 11)]:
    label, votes, neighbors = classify(x, examples)
    print(f"{name}: {label}, {votes} of 3")
changed = [(x, "gold" if x == 12 else label) for x, label in examples]
label, votes, neighbors = classify(11, changed)
print(f"changed B: {label}, {votes} of 3")
assert neighbors.count("blue") == 2
# Agreement is not calibrated probability. No test labels are used here.
```

```text
A: blue, 2 of 3
B: blue, 3 of 3
changed B: blue, 2 of 3
```

The labels/numbers are fictional. Neighbor agreement is not calibrated probability and no held-out accuracy claim is made. A three-card paper vote models the count, not the entire learning process. Ask: which group has more agreement? Answer: B initially. Does that guarantee correctness? No. Changing one label reduces agreement while leaving the majority blue.
