## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
label = "red kite"
new = label.replace("red", "blue")
print(new)
```

Expected terminal output:

```text
blue kite
```

str.replace returns a new string and replaces every occurrence by default, not only whole words. A count argument can limit replacements.

## Change one input

```python
label = "red boat"
```
