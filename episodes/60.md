# Episode 60: Klic Changes His Favorite! Dictionary Update

*Companion guide prepared; video release is pending.*

**Learning goal:** Assign a new value to the same key

**Prerequisites:** [Episode 59](./59.md).

## Try the real Python

Run this in a local Python 3 environment with a trusted grown-up. The terminal displays the output; the code does not move story props.

```python
robot = {'color': 'blue'}
robot['color'] = 'green'
print(robot['color'])
```

Expected terminal output:

```text
green
```

## Change one thing

Predict the result before running this fresh example.

```python
robot = {'color': 'blue'}
robot['color'] = 'yellow'
print(robot['color'])
```

Expected terminal output:

```text
yellow
```

## Try it together

Change the shown input, predict the result and compare with the terminal. Write the predicted output on paper first, run with a grown-up, and compare. Use fictional names and practice values.

## What to notice

- Assign a new value to the same key
- The characters operate physical story props by hand; this code only produces the displayed terminal output.
