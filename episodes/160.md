# Can One Tap Light the Parade?

Published November 20, 2026 with English captions. [Watch the Short](https://www.youtube.com/shorts/r3XjnPYS4iM)

Four lanterns hang over a garden bridge. Nico sets the dial to **three laps**. Klic taps the switch once. On every lap, the clockwork firefly moves to the next dark lantern and lights it. How many lanterns will glow?

## Be the firefly

Put four coins in a row, all tails up. One person sets the number of laps and taps the table **once** to start. The other person moves along the row, turning exactly one coin over on each lap.

Try three laps. Point to the lantern still waiting in the dark. Reset all four coins and try four laps. Can you make zero lanterns glow while still tapping the switch once?

## Try the loop in Python

```python
def parade(laps):
    lanterns = ["dark"] * 4
    for spot in range(laps):
        lanterns[spot] = "glow"
    return lanterns

print(parade(3))
print(parade(4))
```

Use whole numbers from **0 to 4** for this four-lantern game. With three laps, the result is `['glow', 'glow', 'glow', 'dark']`. With four, all four entries say `'glow'`. Every call starts a fresh parade.

A loop repeats an instruction. In this garden, one tap starts the loop and the number of laps controls how many lanterns the firefly reaches.
