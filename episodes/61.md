## Working project

```python

def cheer(name):
    print('Great job, ' + name)

toys = ['ball', 'kite']
toys.append('car')
for toy in toys:
    print(toy)
cheer('Klic')
print(len(toys))

```

Expected terminal output:

```text

ball
kite
car
Great job, Klic
3

```
