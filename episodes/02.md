# Episode 2: Loop It!

[Watch Episode 2](https://www.youtube.com/shorts/6h5Q2iLuwJ0)

**Concept:** Loops  
**Learning goal:** Recognize that a loop repeats an action a specified number of times.

One GRAB action inside REPEAT ×3 collects exactly three stars.

## Learning path

Watch Episode 1, then notice repeated actions.

## Try it together

Clap three times using one instruction: repeat clap three times.

## Check understanding

**Ask:** How many times does GRAB run?

**Answer:** Three times.

## For grown-ups

These short stories introduce a concept through visible action. Colored blocks are simplified pseudocode, not the syntax of every programming language. Pause, predict, and retell the sequence together. No account, personal information, passwords, or paid tool is needed for this activity.
