# Episode 86: Start With the Same Sample! Python Test Fixtures

Natively scheduled for **2026-10-13T10:20:00-05:00 (America/Chicago)**. Public playback and manual English captions will be checked after release.

**Learning goal:** Create a small repeatable test fixture and change only its data to check a second behavior.

**Prerequisites:** [Lesson 66](./66.md), [Lesson 68](./68.md), [Lesson 83](./83.md), [Lesson 85](./85.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
def label(data):
    return data.get('color', 'blue')
sample = {}
print(label(sample))
```

Expected terminal output:

```text
blue
```

sample is our fixed fictional test fixture. An empty dictionary tests the missing-color fallback. A dictionary containing color tests the supplied value. Each complete run initializes sample again.

## Change one input

```python
def label(data):
    return data.get('color', 'blue')
sample = {'color': 'red'}
print(label(sample))
```

Expected terminal output:

```text
red
```

## What the story shows

The fixture is fictional practice data, not a real child profile or network setting. Python returns terminal text. Characters insert physical color cards by hand.

## Try it together

With a grown-up, save and run the complete example twice and confirm blue both times. Change only sample to the red dictionary and rerun for red. Restore sample to an empty dictionary and confirm blue again. The initial fixture makes the test repeatable; do not use names, addresses, passwords, or real profiles.
