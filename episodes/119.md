# Episode 119 — Who Helps the App? Meet Linux

[Watch Episode 119](https://www.youtube.com/shorts/CSrU5Ul6TZM). Public playback and manual English captions verified October 18, 2026.

**Learning objective:** Distinguish an app, an operating system, and hardware; identify Linux as a kernel within a complete system.

**Prerequisites:** None. A grown-up can help read the vocabulary.

Nico pulls back a clubhouse curtain. Klic holds a drawing-app card beside a model of three layers, then places it above the operating-system layer. Later he swaps the drawing app for a music app. The system and hardware remain in the model.

| Word | Meaning | Example |
| --- | --- | --- |
| App | Software for a task | A drawing or music app |
| Hardware | Physical computer parts | Screen, memory, processor |
| Operating system | Software that helps apps use and share hardware resources | A complete Linux-based operating system |
| Kernel | A core part of an operating system | Linux |

Linux is the kernel. A complete usable system also includes other software. The [Linux Kernel Archives explanation](https://www.kernel.org/linux.html) distinguishes the kernel from a complete distribution.

## Predict, reveal, change

- **Predict:** Does the drawing-app card belong above the system or inside the screen?
- **Reveal:** Above the system in our model. A drawing app is software; a screen is hardware.
- **Change:** Replace the drawing app with a music app. The app changes; the system and hardware cards remain.
- **Recall:** Is Linux the same thing as a screen? No. Linux is software: a kernel within the system.

## Grown-up activity

1. Draw three cards: a music app, an operating system, and a screen. Use drawings or fictional labels.
2. Arrange them as app → system → hardware.
3. Replace the music app with a drawing app. Ask which cards stay.
4. Ask your learner to point to the physical thing. Answer: the screen.

No installation, account, personal information, or commands are needed. This is a simplified conceptual model, not an API diagram or a demonstration of a running Linux computer. Real apps can use libraries and system services. No code or terminal output is shown in this lesson.
