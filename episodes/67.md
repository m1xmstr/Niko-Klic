# Episode 67: Did We Pack the Brush? Python in

Video release pending. This guide contains prepared Python examples; it is not a claim that the video is published.

**Learning goal:** Check whether an exact named value is in a list, producing True or False.

**Prerequisites:** [Episode47](./47.md), [Episode48](./48.md), [Episode54](./54.md).

## Run real Python

With a trusted grown-up, use a local Python 3 environment. First predict the terminal output. Python prints text; the story props are moved by the characters. No account or personal information is needed.

```python
tools = ['sponge', 'cloth']
print('brush' in tools)
```

Expected terminal output:

```text
False
```

The name on the left of in is checked against the list on the right. Keep quotes around brush.

## Change one thing

Run this fresh example separately and compare:

```python
tools = ['sponge', 'cloth', 'brush']
print('brush' in tools)
```

Expected terminal output:

```text
True
```

## What the story shows

Python prints text in the terminal; the characters manually check and pack props. Membership is an exact match, not an internet search.

## Try it together

Use two fictional supplies, predict whether pencil is listed, then add pencil and rerun. Do not enter private information. A grown-up can write the two possible results on paper, pause for your prediction, and help you compare with the terminal. Use only made-up practice values.

**Ask:** Why did False become True?

**Answer:** The exact brush value was added to the list.
