# Episode 136 — Which Clue Matches? Linux grep

Status: In production; video not yet scheduled or published.

## Learning goal

Use `grep` to find matching lines in a small saved text file. Change the search text and compare the output without changing the file.

Prerequisite: [Episode 134 — Read a file with cat](134.md).

## The story

In a forest clearing, Klic slides a reading window over three clue cards. Nico lifts the matching moon card, then they try a different search. The paper board illustrates text matching; no physical device is controlled.

## Try it with a grown-up

Use a new practice folder on a Linux computer. Save a plain-text file named `clues.txt` containing exactly these lowercase lines:

```text
moon by the pond
sun by the bridge
star by the tree
```

Open a terminal in that folder. Run:

```sh
grep moon clues.txt
```

Recorded output:

```text
moon by the pond
```

Predict what this changed command will show:

```sh
grep sun clues.txt
```

Recorded output:

```text
sun by the bridge
```

`grep` is the command, the next argument is the search pattern, and `clues.txt` is the file to read. Spaces separate those arguments. The result is the **whole matching line**, not just the word. These commands leave the file unchanged.

This example uses lowercase literal text. Default matching is case-sensitive, and a pattern can match part of a longer word. More advanced patterns have special meanings; we are not teaching those here. `grep` matches text, not the meaning of a clue.

The demonstration ran with GNU grep 3.11 in a disposable Linux practice folder. Both recorded commands succeeded, the file hash was identical before and after, and reopening the file returned all three original lines. The practice fixture was removed afterward.

## Offline activity

Write the three clues on separate cards. Slide a paper window over them and select each card containing `moon`. Change the search to `sun`. Add a second fictional moon clue and predict how many lines would match.

## Check understanding

- **Does grep change the file?** These searches do not; the saved lines stay the same.
- **Does it show only the matching word?** No. With these commands, it shows each complete matching line.
- **Why does the result change?** We changed the search pattern from `moon` to `sun`.
- **Does a matching clue have to be true?** No. Text matching does not verify a statement.

Use fictional clues only and practice with a grown-up. Original illustrated characters and synthetic voices; no personal data or remote hosts are involved.
