## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
boxes = 3
slots = 2
print(boxes * slots)
```

Expected terminal output:

```text
6
```

Three boxes with two slots each means multiplication. Addition produces five without an exception, but does not answer this question.

## Change one input

```python
boxes = 4
slots = 2
print(boxes * slots)
```

Expected terminal output:

```text
8
```

## What the story shows

The program displays a count in a terminal. Python does not move boxes or operate equipment. A logic error may finish without an exception.

## Try it together

With a grown-up, save the complete program in a new practice file. Predict six before running. Replace the star with plus and compare five: the program finishes but answers the wrong question. Restore multiplication and change boxes to four. Predict eight, then run. Use fictional counts only.

## A program can run and still be wrong

```python
boxes = 3
slots = 2
print(boxes + slots)
```

Actual output:

```text
5
```

This run finishes without an exception, but addition does not count the total slots. Compare the expected six with the actual five, then use multiplication as in the working example.
