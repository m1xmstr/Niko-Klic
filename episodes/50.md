# Episode 50: Three Checks, One Python Loop!

*Companion guide prepared; video release is pending.*

**Learning goal:** This range supplies zero, one and two; adding one displays station numbers one, two and three.

**Prerequisites:** [Episode 2](./02.md), [Episode 23](./23.md), [Episode 44](./44.md).

## Try the real Python

Run this in a local Python 3 environment with a trusted grown-up. The terminal displays the output; the code does not move story props.

```python
for step in range(3):
    print(step + 1)
```

Expected terminal output:

```text
1
2
3
```

## Change one thing

Predict the result before running this fresh example.

```python
for step in range(2):
    print(step + 1)
```

Expected terminal output:

```text
1
2
```

## Try it together

## Read the important line

`range(3)` supplies 0, 1, and 2: it stops **before** 3. On each pass, `step` gets the next value. The indented `print` belongs inside the loop. `step + 1` makes the displayed labels start at 1, so the output is 1, 2, 3. Changing only the range to `range(2)` gives two passes. The code repeats the print instruction; Klic's garden actions are a story demonstration.
