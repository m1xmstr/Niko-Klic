# Episode 46: Why Is Klic's Variable Still Zero?

Video publication pending.

**Learning goal:** The right side uses the old value; assignment stores the new value under the same name.

## Learning path

Prerequisites: [Episode 6](06.md), [Episode 26](26.md), [Episode 44](44.md).

## Run the code

```python
stars = 0
stars = stars + 1
print(stars)
```

Terminal output:

```text
1
```

## Change one thing

```python
stars = 2
stars = stars + 1
print(stars)
```

Terminal output:

```text
3
```

The right-hand side reads the old value. `stars + 1` adds one; `=` stores the result back in `stars`. The variable name stays the same.

## Try it together

Replace zero with two and predict three before running. An adult can help run this in a local Python 3 editor. Offline, write each line on paper and predict the terminal output before uncovering it.
