# 151 — Did the New Word Follow the Example?

Status: Scheduled for November 11, 2026 at 10AM Central. Public playback verification waits for release.

[Watch Episode 151](https://youtube.com/shorts/XCiQY71Bl3c)

An example can guide a language model's reply. We still need to check the whole reply before using it.

## Predict, then compare

Nico and Klic are checking fictional badges. Their request asks for only the new badge. The example changes capital letters to lowercase and puts the word inside round brackets.

System instruction:

```text
Return only the new badge.
```

First request:

```text
Make a pretend badge following this example.
Example: SUN -> (sun)
New word: KITE
Badge:
```

Before revealing the reply, predict it. The requested badge is `(kite)`.

The actual recorded reply was:

```text
KITE -> (kite)
```

The word is preserved in lowercase, but the reply also includes the original word and an arrow. It does not follow the instruction to return only the badge.

## Change just one word

Keep the same system instruction and example. Change only `KITE` to `BOAT`:

```text
Make a pretend badge following this example.
Example: SUN -> (sun)
New word: BOAT
Badge:
```

Predict again. The requested badge is `(boat)`. The actual recorded reply was:

```text
BOA -> (boa)
```

The reply leaves out the letter **T**, as well as including extra text. Brackets alone do not make an answer correct. Nico and Klic catch both problems before using the replies.

## What was actually tested?

Three independent requests to a local `llama3.2:3b` model produced `KITE -> (kite)`, `BOA -> (boa)`, and `KITE -> (kite)`. The third request repeated the first without earlier conversation history. These are recorded results, not promised outputs for every model or run.

The example was included in each request. This did not retrain the model, print a badge, or control hardware. The demonstration does not measure general reliability.

## Try together

With a grown-up, choose one pretend word. Write the badge you expect before asking a model. Compare every letter, the letter case, both brackets, and any extra text. A grown-up can check a manually corrected badge before using it. Never enter private names or personal information for this activity.

**Takeaway:** Check the whole reply, even when part of it looks right.
