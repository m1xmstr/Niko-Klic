# Episode 81: Can Python Handle Zero Boxes? try and except

Natively scheduled for **2026-10-12T10:40:00-05:00 (America/Chicago)**. Public playback and manual English captions will be checked after release.

**Learning goal:** Catch ZeroDivisionError with a specific except block and compare the error response with a successful calculation.

**Prerequisites:** [Lesson 46](./46.md), [Lesson 49](./49.md), [Lesson 80](./80.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
boxes = 0
try:
    print(6 // boxes)
except ZeroDivisionError:
    print('Add boxes')
```

Expected terminal output:

```text
Add boxes
```

try runs the indented division. If it raises ZeroDivisionError, the matching except block displays Add boxes. With boxes set to three, division succeeds and the handler is skipped.

## Change one input

```python
boxes = 3
try:
    print(6 // boxes)
except ZeroDivisionError:
    print('Add boxes')
```

Expected terminal output:

```text
2
```

## What the story shows

Python displays a message or number on screen. Handling the exception does not make division by zero possible. The carrier and tray are a physical analogy opened by hand.

## Try it together

With a grown-up and a local Python editor, save the shown program in a new practice folder. Run it with boxes equal to zero and compare Add boxes. Change only boxes to three and rerun to compare 2. Try two and predict 3. Keep except specific; do not hide every error.
