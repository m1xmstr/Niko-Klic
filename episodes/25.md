# Episode 25: What’s in the Box?

Prepared; not yet publicly released.

**Concept:** variables  
**Learning goal:** Recognize that a named variable stores a value that can change.

One pretend battery joins another. ENERGY changes from 1 to 2 while its name stays the same, and Klic celebrates.

## Learning path

Episode 6 (variables).

## Try it together

Label a paper box ENERGY. Put one paper battery beside it and write 1 on a value card. Add one paper battery and replace the card with 2. Keep the name unchanged. This is a model of a variable, not a real computer component.

## Check understanding

**Ask:** What stays the same when ENERGY changes from 1 to 2?

**Answer:** The name ENERGY stays the same. Its stored value changes.

## For grown-ups

Colored blocks are simplified pseudocode. Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed for these activities.
