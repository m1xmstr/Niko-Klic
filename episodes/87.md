# Episode 87: Does Exactly Five Count? Python Boundary Tests

Natively scheduled for **2026-10-13T10:30:00-05:00 (America/Chicago)**. Public playback and manual English captions will be checked after release.

**Learning goal:** Check an inclusive threshold at five and just below five to detect an off-by-one mistake.

**Prerequisites:** [Lesson 38](./38.md), [Lesson 62](./62.md), [Lesson 83](./83.md), [Lesson 85](./85.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
count = 5
if count >= 5:
    print('ready')
else:
    print('wait')
```

Expected terminal output:

```text
ready
```

count >= 5 includes exactly five. Testing five and four distinguishes the boundary from the value just below it.

## Change one input

```python
count = 4
if count >= 5:
    print('ready')
else:
    print('wait')
```

Expected terminal output:

```text
wait
```

## What the story shows

Python prints ready or wait in the terminal. The tray is a physical analogy handled by the characters, not controlled by this code.
