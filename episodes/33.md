# Episode 33: Why Won’t It Ring? Klic’s Event Listener

Prepared; not yet publicly released.

**Concept:** event listeners  
**Learning goal:** The program waits for the event, then responds.

A bell has a listening rule and stays silent while nobody clicks. The program waits for the event, then responds.

## Learning path

Earlier lessons: 10. Revisit these ideas before trying this activity.

## Try it together

Take turns being a button and a bell. The bell says ding only after the other person says click.

## Check understanding

**Ask:** What does the event listener wait for?

**Answer:** A click; then it runs the ring action.

## For grown-ups

Colored blocks are simplified pseudocode. Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed for these activities.
