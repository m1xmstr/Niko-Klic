# Episode 73: Found Blue! Why Python break Stops the Search

Video natively scheduled for **2026-10-11T10:20:00-05:00 (America/Chicago)**. Public playback and manual English captions will be checked after release.

**Learning goal:** Stop checking the rest of a list as soon as a chosen label is found.

**Prerequisites:** [Episode 48](./48.md), [Episode 49](./49.md), [Episode 58](./58.md).

## Run real Python

With a trusted grown-up, use a local Python 3 environment. Predict the terminal output before running the full example. No account or private information is needed.

```python
labels = ['red', 'blue', 'gold']
for label in labels:
    print(label)
    if label == 'blue':
        break
```

Expected output:

```text
red
blue
```

break leaves this loop immediately. print comes before the check, so the matching label appears too; the gold label is not reached.

## What the story shows

These are made-up labels on disconnected practice props. Python prints the labels examined and stops this loop; it does not scan a network, unplug a device, or stop the whole computer.
