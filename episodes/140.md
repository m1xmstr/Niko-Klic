# Lamp or Bell First? Linux Logs

Nico and Klic need a cue card for a pretend show. They read a saved log, then update their card when a second recording has a different order.

**Objective:** Read timestamps in a short saved log and distinguish recorded order from sorting. Prerequisite: [Episode 134 — reading saved text with cat](134.md).

## Recorded example

In a disposable Linux practice folder, `show.log` contains:

```text
09:00 doors open
09:01 lamp on
09:02 bell rings
```

Run:

```sh
cat show.log
```

The output is the three lines above. The lamp is recorded at 09:01, before the bell at 09:02.

## Changed case: predict before reading the answer

Save this different fictional log in the practice file:

```text
09:00 doors open
09:01 bell rings
09:02 lamp on
```

Run `cat show.log` again. Which event is recorded first: bell or lamp? Compare both timestamps before answering.

**Answer:** Bell, at 09:01. The lamp is at 09:02. Our revised cue card is BELL → LAMP.

## What cat does—and what it does not do

`cat` displays the saved lines in file order. These examples were already saved in time order; `cat` did not sort them. A separate recorded check with 09:02 before 09:01 preserved that unsorted order. Reading a log also does not prove that a real-world event happened or that a clock was correct. All events here are fictional, on one pretend morning. No lamp, bell, or other hardware was controlled.

## Try together

With a grown-up, write three pretend events on paper, each with a different time from the same hour. Mix the cards. Compare their times and arrange them. Change two timestamps and explain why the order changes.

Optional Linux activity: use a new practice folder and a text editor to save only these fictional lines as `show.log`. Run `cat show.log`; change the lines, save, close and reopen the file, then run the command again. Avoid editing system logs or real personal data.

Questions:

- Does `cat` rearrange the file? **No.**
- Does the first printed line always have the earliest time? **Only if the saved lines are already ordered that way.**
- Why did our cue card change? **The changed log recorded the bell before the lamp.**

The examples were executed with GNU cat 9.5 on Linux in a disposable environment; saved results were checked in a fresh shell, practice files removed, and the environment stopped.
