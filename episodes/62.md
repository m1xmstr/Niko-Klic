# Episode 62 — Both Ready? Python `and` Opens the Trail

**[Watch Episode 62](https://youtube.com/shorts/cHgJ6BPnFFw)** This guide contains working examples for this lesson.

Python `and` combines two checks. In this lesson, both Boolean values must be `True` for the combined result to be `True`.

Learning objective: predict the result of two Boolean checks, change one value, and compare the exact terminal output.

Prerequisites: [comparisons in Episode 48](48.md), [if/else in Episode 49](49.md), and the [Python toolbox review](61.md).

## Try the first example

```python
helmet = True
light = True
print(helmet and light)
```

Expected terminal output:

```text
True
```

The word `and` sits between the two values. Here both are `True`, so the combined result is `True`. Capital letters matter in Python: write `True` and `False` exactly as shown.

## Change one value

Predict the output before running this version:

```python
helmet = True
light = False
print(helmet and light)
```

Expected terminal output:

```text
False
```

The helmet value stayed `True`, but the light value became `False`. `and` needs both Boolean checks to be `True`. One ready check alone is not enough.

These examples use Boolean values. Python's `and` can also work with other kinds of values; that broader behavior is outside this lesson.

## Separate the story from the program

Nico and Klic move pretend props by hand. `print(...)` displays text in the terminal. This program does not fasten a helmet, control a flashlight, inspect equipment, or establish that a real activity is safe.

A later game could combine two checks, such as having a pretend key **and** reaching a pretend door. The code helps express the rule; the game still needs instructions to act on the result.

## Try it with a grown-up

Make two paper cards labeled `key` and `door`. Give each a `True` or `False` side. Turn the cards and predict the combined answer. Then, with a grown-up, try changing the two Boolean values in the Python example.

| First value | Second value | Result of `and` |
| --- | --- | --- |
| `True` | `True` | `True` |
| `True` | `False` | `False` |
| `False` | `True` | `False` |
| `False` | `False` | `False` |

Question: If the first card is `False` and the second is `True`, does the combined check pass?

Answer: No. The result is `False` because both checks must be `True`.
