# Episode 141 — Which Label Fits?

Status: Scheduled for November 4, 2026 at 10 AM America/Chicago. [Video](https://www.youtube.com/shorts/ifv0btasZWQ). Manual English captions are published; public playback verification waits for release.

One example can show a language model the format you want. We still check its reply.

Nico needs matching shelf labels for two pretend books. Before the first reveal, choose `owl` or `[OWL]`. Before the changed case, predict the label for `sun`.

## Try the recorded request

With a grown-up, use a local language model with system instruction `Return only the new label.` and this prompt:

```text
Make a shelf label using the same bracket and capital-letter pattern as the example.
Example: fox -> [FOX]
New word: owl
Label:
```

Our local `llama3.2:3b` returned `[OWL]`. In a separate request, changing only `New word: owl` to `New word: sun` returned `[SUN]`. A fresh independent original request returned `[OWL]` again. The recorded runs used temperature 0 and seed 141; another model or run can differ.

Check all three details: the right word, capital letters, and both brackets. The example is part of each request; it does not train the model or guarantee the answer. These are fictional labels, with no printer or other hardware controlled.

## Practice together

Write one pretend word on paper. Predict its label, then ask your model and compare. If it misses a bracket, uses the wrong word, or adds extra text, describe the mismatch and revise the request. Keep personal information out of prompts.
