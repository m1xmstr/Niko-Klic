# Episode 74: Skip the Empty Name! Python continue

Video in preparation; not uploaded or scheduled. These Python examples have been executed locally and do not imply media approval or release.

**Learning goal:** Skip an empty string while continuing to process the later entries in a list.

**Prerequisites:** [Episode 47](./47.md), [Episode 49](./49.md), [Episode 58](./58.md), [Episode 73](./73.md).

## Run real Python

With a trusted grown-up, use a local Python 3 environment. Predict the terminal output before running the full example. No account or private information is needed.

```python
names = ['Moon', '', 'Star']
for name in names:
    if name == '':
        continue
    print(name)
```

Expected output:

```text
Moon
Star
```

Two quotes with nothing between them make an empty string. continue skips the remaining lines for that entry and moves to the next one; it does not end the loop.

## Change one thing

Run this fresh example separately:

```python
names = ['Moon', 'Sun', 'Star']
for name in names:
    if name == '':
        continue
    print(name)
```

Expected output:

```text
Moon
Sun
Star
```
