# Episode 144 — New Name, Same Clue!

Status: Scheduled for November 5, 2026 at 3PM Central. Public playback verification waits for release.

[Watch Episode 144](https://www.youtube.com/shorts/hwFd77iAn6E)

Nico's pretend treasure note needs a new name. In this lesson, `mv` renames one practice file within the same folder. The destination does not already exist. We check the result instead of assuming the clue survived.

## Try it with a grown-up

Use Linux with GNU Coreutils in a disposable practice folder. These commands create only a fictional clue. Start with a fresh folder so neither destination already exists:

```sh
practice_dir=$(mktemp -d)
cd "$practice_dir"
printf '%s\n' 'look under the tree' > note.txt
cat note.txt
sha256sum note.txt
```

Predict whether renaming changes the words. Then run:

```sh
test ! -e clue.txt && mv note.txt clue.txt
test ! -e note.txt && printf '%s\n' 'old name absent'
cat clue.txt
sha256sum clue.txt
```

Our recorded checks showed the old name was absent, the text was still `look under the tree`, and the checksum matched the original.

Now predict the result of another rename:

```sh
test ! -e map.txt && mv clue.txt map.txt
test ! -e clue.txt && printf '%s\n' 'old name absent'
cat map.txt
sha256sum map.txt
```

The text and checksum matched again. A fresh shell independently checked `map.txt`, both absent old names, and the same checksum. The file identity also stayed the same in this single-folder example.

## What the example means

The first name identifies the source; the second names the destination. Our two destinations were absent. **Do not practice on valuable files or existing destination names:** plain `mv` can replace an existing file. Moving across filesystems has additional behavior, outside this lesson. See the [GNU mv documentation](https://www.gnu.org/software/coreutils/manual/html_node/mv-invocation.html).

The animated treasure card illustrates the recorded file checks. No real treasure or equipment is controlled. Our disposable Linux files were removed after verification.

## Practice together

Write a clue on paper, then change only its label. Predict which parts change and which stay the same. With a grown-up, compare that prediction with a disposable file rename and read the file afterward.
