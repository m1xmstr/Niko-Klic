# Episode 16: Keep It Secret!

Prepared; not yet publicly released.

**Concept:** passwords  
**Learning goal:** Do not send passwords in messages; seek trusted adult help.

A fictional request for a masked password is closed; the lock stays shut.

## Learning path

After Episode 12 privacy. Never use real passwords.

## Try it together

With pretend paper messages, practice saying no and asking an adult.

## Check understanding

**Ask:** Should Klic send a password in a message?

**Answer:** No. Keep it private and ask a trusted grown-up.

## For grown-ups

Colored blocks are simplified pseudocode. Pause, predict, and retell the steps together. Use pretend examples for safety lessons; never enter real passwords or private information. No account or paid tool is needed for these activities.
