# Episode 23: Pick One From the List!

Prepared; not yet publicly released.

**Concept:** indexing  
**Learning goal:** Use an index to choose an item from a list that starts at zero.

Ball, car and kite occupy three list positions. Klic checks indices zero, one and two, then selects two and flies the kite.

## Learning path

Episode 11 (lists). This example is zero-based; not every programming language starts at zero.

## Try it together

Line up three toys. Label the spaces 0, 1 and 2. Ask for a toy by its index, then switch roles.

## Check understanding

**Ask:** Which index holds the kite in [BALL, CAR, KITE]?

**Answer:** Index 2. The first item is at 0, the second at 1, and the third at 2 in this zero-based example.
