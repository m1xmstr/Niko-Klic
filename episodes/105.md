## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
label = "BLUE"
normal = label.lower()
print(normal)
print(normal == "blue")
```

Expected terminal output:

```text
blue
True
```

lower returns a lowercase copy. Equality still compares the resulting text exactly; this is not a universal identity or language matching system.

## Change one input

```python
label = "GREEN"
normal = label.lower()
print(normal)
print(normal == "blue")
```

Expected terminal output:

```text
green
False
```
