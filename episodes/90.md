# Episode 90: Stop Repeating That Rule! Python Refactoring

Video in preparation; no native schedule yet.

**Learning goal:** Put a repeated calculation in one named function, check unchanged results, then change one input.

**Prerequisites:** [Lesson 59](./59.md), [Lesson 63](./63.md), [Lesson 75](./75.md), [Lesson 85](./85.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
def pair_count(boxes):
    return boxes * 2
print(pair_count(3))
print(pair_count(4))
```

Expected terminal output:

```text
6
8
```

Both calls reuse boxes * 2 inside pair_count. Refactoring changes structure while preserving behavior for the same inputs.

## Change one input

```python
def pair_count(boxes):
    return boxes * 2
print(pair_count(5))
print(pair_count(4))
```

Expected terminal output:

```text
10
8
```

## What the story shows

Python displays numbers in the terminal. It does not print paper or control the desk. Each fictional box holds two items.

## Try it together
