## Working Python

With a trusted grown-up, run this complete example in a local Python3 environment. Use fictional values only.

```python
counts = [2, 3, 1]
total = sum(counts)
print(total)
```

Expected terminal output:

```text
6
```

sum(counts) adds numeric values, with default starting value 0. len(counts) counts elements instead. sum([]) returns 0.

## Change one thing

```python
counts = [2, 3, 4]
total = sum(counts)
print(total)
```

Expected output:

```text
9
```

**Ask:** Why is len not the total?

**Answer:** len counts list items; sum adds their numeric values.
