## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
from ipaddress import ip_address
address = ip_address("127.0.0.1")
print(address.version)
print(address.is_loopback)
```

Expected terminal output:

```text
4
True
```

address.is_loopback checks whether the address belongs to a loopback range. 127.0.0.1 is IPv4 loopback, referring to the same host. 192.0.2.8 is a documentation address, not a real destination for this exercise.

## Change one input

```python
from ipaddress import ip_address
address = ip_address("192.0.2.8")
print(address.version)
print(address.is_loopback)
```

Expected terminal output:

```text
4
False
```

## What the story shows

Python classifies address text. It sends no message and opens no connection. The toy return chute illustrates staying on the same host, not a real network test.
