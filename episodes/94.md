# Episode 94: Is the Saved Note Really There? Python exists

Video in preparation; no native schedule yet.

**Learning goal:** Save a tiny practice file and use Path.exists to check a present and absent path.

**Prerequisites:** [Lesson 78](./78.md), [Lesson 79](./79.md), [Lesson 93](./93.md).

## Working example

With a grown-up, use a local Python 3 editor and a new empty practice folder. No account or private information is needed.

```python
from pathlib import Path
Path("note.txt").write_text("blue")
p = Path("note.txt")
print(p.exists())
```

Expected terminal output:

```text
True
```

p.exists() reports whether a file or folder exists at p. The first instruction writes blue into note.txt in the working folder. Changing only the checked path to missing.txt returns False in a fresh practice folder.

## Change one input

```python
from pathlib import Path
Path("note.txt").write_text("blue")
p = Path("missing.txt")
print(p.exists())
```

Expected terminal output:

```text
False
```

## What the story shows

This program really writes note.txt in the current working folder. Run only in a new empty practice folder with a grown-up; write_text replaces that file if it already exists. The drawer is an analogy. exists does not tell us what a file contains.

## Try it together

With a grown-up, create a new empty practice folder and run the working program there. Reopen note.txt to verify blue was saved. Run the changed version: missing.txt does not exist and the result is False. Check that note.txt still contains blue. Do not run this over personal files.
