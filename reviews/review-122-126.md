## 122: Test a machine-learning prediction

Four fictional training cards fit group averages: PEA sizes 2,3 give 2.5; SUNFLOWER sizes 7,8 give 7.5. The model is saved and reopened before test predictions. The two test labels are not used to fit it. Input 4 predicts PEA, disagreeing with its SUNFLOWER label. Changed input 6 predicts SUNFLOWER correctly. The model is unchanged between tests. This tiny 1/2 result is not reliable real-world accuracy. An exact tie uses the first training label, PEA.

Save this exact Python standard-library demonstration as classifier.py in a new practice folder, reopen it, and run with Python 3. It writes only trained-model.json beside itself.

```python
"""Fictional seed cards: training labels fit centroids; test labels only score predictions."""
import json
from pathlib import Path
from statistics import mean
training = {'PEA': [2, 3], 'SUNFLOWER': [7, 8]}
model = {label: mean(sizes) for label, sizes in training.items()}
path = Path(__file__).with_name('trained-model.json')
path.write_text(json.dumps(model, indent=2) + '\n')
model = json.loads(path.read_text())
def predict(size):
    # An exact tie chooses PEA because it is first in the training mapping.
    return min(model, key=lambda label: abs(size-model[label]))
print('TRAINING:', training)
print('SAVED AND REOPENED CENTROIDS:', model)
test_cards = [(4, 'SUNFLOWER'), (6, 'SUNFLOWER')]
correct = 0
for size, label in test_cards:
    guess = predict(size)
    matched = guess == label
    correct += matched
    print(f'Size {size}: prediction={guess}, label={label}, match={matched}')
print(f'Tiny test: {correct}/{len(test_cards)} correct; not real-world accuracy.')
assert model == {'PEA': 2.5, 'SUNFLOWER': 7.5}
assert predict(4)=='PEA' and predict(6)=='SUNFLOWER' and predict(5)=='PEA'
assert correct==1
```

Recorded output:

```text
TRAINING: {'PEA': [2, 3], 'SUNFLOWER': [7, 8]}
SAVED AND REOPENED CENTROIDS: {'PEA': 2.5, 'SUNFLOWER': 7.5}
Size 4: prediction=PEA, label=SUNFLOWER, match=False
Size 6: prediction=SUNFLOWER, label=SUNFLOWER, match=True
Tiny test: 1/2 correct; not real-world accuracy.
```

**Predict:** Does learning guarantee the new size-4 label is right? **Answer:** No; compare the prediction with the withheld answer label.

## 123: Tokens and evidence

The pinned Qwen2.5-Coder tokenizer used for this demonstration splits `playground` into `[play] [ground]` and `The train is` into `[The] [ train] [ is]`. Leading spaces belong to the latter tokens. ` red` and ` blue` each form a single token in that tokenizer. Token boundaries depend on tokenizer and context. This was real tokenization, **not LLM inference or measured probabilities**.

The human-selected sentence endings are “The train is red.” and “The train is blue.” Both can be plausible English; only red matches the toy shown. A possible continuation does not establish a fact. With a grown-up, change a word card and compare it with the physical toy.
