## Lesson 109: float

Convert valid decimal text before calculating

```python
text = "2.5"
length = float(text)
print(length + 1)
```

Expected terminal output:

```text
3.5
```

Change one input and run the complete example again:

```python

length = float(text)
print(length + 1)
```

Expected terminal output:

```text

```

## Lesson 111: f-string

Build readable text from a value at evaluation time

## Lesson 112: startswith

Check an exact prefix without making a security claim

```python

print(name.startswith("draft_"))
```

Expected terminal output:

```text
True
```

Change one input and run the complete example again:

```python

```

```text

```

## Complete project: Our pretend workshop report

Save the whole program below in one Python file. The video uses two source pages for readability; page two uses the definitions on page one. Predict every output line before running.

```python
text = "2.4"
name = "draft_red kite"
length = float(text)
whole = round(length)
label = name.replace("red", "blue")
is_draft = name.startswith("draft_")
print(f"Length: {whole}")
print(label)
print(is_draft)
```

Expected terminal output:

```text
Length: 2
draft_blue kite
True
```
