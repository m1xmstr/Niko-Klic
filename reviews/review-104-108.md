## Lesson 104: strip

Remove outside whitespace; keep the original

```python
label = "  Star  "
clean = label.strip()
print(clean)
print(len(clean))
```

Expected terminal output:

```text
Star
4
```

Change one input and run the complete example again:

```python
label = "  Moon  "
clean = label.strip()
print(clean)
print(len(clean))
```

Expected terminal output:

```text
Moon
4
```

## Lesson 105: lower

Normalize letter case before an exact comparison

```python
label = "BLUE"
normal = label.lower()
print(normal)
print(normal == "blue")
```

Expected terminal output:

```text
blue
True
```

Change one input and run the complete example again:

```python
label = "GREEN"
normal = label.lower()
print(normal)
print(normal == "blue")
```

Expected terminal output:

```text
green
False
```

## Lesson 106: split

Turn one string into a list using a separator

```python
text = "red,blue"
colors = text.split(",")
print(colors)
print(len(colors))
```

Expected terminal output:

```text
['red', 'blue']
2
```

Change one input and run the complete example again:

```python
text = "red,blue,green"
colors = text.split(",")
print(colors)
print(len(colors))
```

Expected terminal output:

```text
['red', 'blue', 'green']
3
```

## Lesson 107: join

Put string items together with a chosen separator

```python
parts = ["red", "blue"]
label = " / ".join(parts)
print(label)
```

Expected terminal output:

```text
red / blue
```

Change one input and run the complete example again:

```python
parts = ["red", "blue", "green"]
label = " / ".join(parts)
print(label)
```

Expected terminal output:

```text
red / blue / green
```

## Lesson 108: int
