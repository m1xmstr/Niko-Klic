## Short 121: A written rule and a learned pattern

The written rule returns BIG for sizes above 5, otherwise SMALL. Separately, fit a tiny nearest-centroid classifier on SMALL examples 2,3 and BIG examples 7,8. The fitted averages are 2.5 and 7.5. Choose the nearest average; exact ties use SMALL. Input 6 gives BIG, and changed input 4 gives SMALL. The written rule agrees both times, but matching results do not show that both methods learned. People choose the examples, labels and method; unfamiliar cases still need checking. Some AI learns from examples, not all AI uses this method.

The following exact demonstration was saved, reopened and executed in a disposable local folder. It writes and reopens only trained-model.json. Save as classifier.py in a new practice folder with a grown-up. This is a transparent standard-library implementation, not the scikit-learn package.

```python
"""Tiny nearest-centroid classifier; fictional size labels, not a real-world AI test."""
import json
from pathlib import Path
from statistics import mean
training = {'SMALL': [2, 3], 'BIG': [7, 8]}
centroids = {label: mean(values) for label, values in training.items()}
model_path = Path(__file__).with_name('trained-model.json')
model_path.write_text(json.dumps(centroids, indent=2) + '\n')
model = json.loads(model_path.read_text())
def predict(size):
    # Stable label order makes exact ties SMALL.
    return min(model, key=lambda label: abs(size - model[label]))
def rule(size):
    return 'BIG' if size > 5 else 'SMALL'
print('TRAINING:', training)
print('SAVED AND REOPENED CENTROIDS:', model)
for size in [6, 4]:
    print(f'Size {size}: rule={rule(size)}, model={predict(size)}')
assert predict(6) == 'BIG' and predict(4) == 'SMALL'
assert predict(5) == 'SMALL'
```

Expected output:

```text
TRAINING: {'SMALL': [2, 3], 'BIG': [7, 8]}
SAVED AND REOPENED CENTROIDS: {'SMALL': 2.5, 'BIG': 7.5}
Size 6: rule=BIG, model=BIG
Size 4: rule=SMALL, model=SMALL
```
