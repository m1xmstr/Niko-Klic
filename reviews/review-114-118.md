## Lesson 114: range

Start, excluded stop and nonzero step

```python
for marker in range(0, 7, 2):
    print(marker)
```

Expected terminal output:

```text
0
2
4
6
```

Change one input and run the complete example again:

```python
for marker in range(0, 7, 3):
    print(marker)
```

Expected terminal output:

```text
0
3
6
```

## Lesson 115: enumerate

Counter and item together; list indices unchanged

```python
toys = ["kite", "boat"]
for number, toy in enumerate(toys, 1):
    print(number, toy)
```

Expected terminal output:

```text
1 kite
2 boat
```

Change one input and run the complete example again:

```python
toys = ["drum", "boat"]
for number, toy in enumerate(toys, 1):
    print(number, toy)
```

Expected terminal output:

```text
1 drum
2 boat
```

## Lesson 116: zip

Pair corresponding positions; default stops at shortest

```python
colors = ["red", "blue"]
shapes = ["star", "moon"]
for color, shape in zip(colors, shapes):
    print(color, shape)
```

Expected terminal output:

```text
red star
blue moon
```

Change one input and run the complete example again:

```python
colors = ["red", "blue"]
shapes = ["star"]
for color, shape in zip(colors, shapes):
    print(color, shape)
```

Expected terminal output:

```text
red star
```

## Complete project: Our pretend exhibition report

Save the whole program below in one Python file. The video uses two source pages for readability; page two uses the definitions on page one. Predict every output line before running.

```python
names = ["kite", "boat"]
counts = [2, 3]
for number, name in enumerate(names, 1):
    print(number, name)
for name, count in zip(names, counts):
    print(name, count)
print("Total:", sum(counts))
print("Largest:", max(counts))
for marker in range(0, 7, 2):
    print(marker)
```

Expected terminal output:

```text
1 kite
2 boat
kite 2
boat 3
Total: 5
Largest: 3
0
2
4
6
```
