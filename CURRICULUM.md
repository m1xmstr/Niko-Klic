# Learning beyond Python

Nico & Klic explores computers and technology through short stories, predictions and grown-up-supported activities. Python is one part of the curriculum.

## Upcoming subject rotation

| Track | Start here | Build toward |
|---|---|---|
| Linux and computers | What an operating system does | Terminal, folders, files, permissions |
| Ansible and automation | Tasks and runbooks | YAML playbooks, checking desired state, repeatable changes |
| AI literacy | Rules and learned patterns | Checking answers, privacy and human oversight |
| Machine learning | Labeled examples and predictions | Separate test examples, data quality and limitations |
| LLMs | Context and token prediction | Clear prompts, tokenization, checking generated answers |

These are upcoming topics, not a claim that the videos are available yet. Lessons rotate between subjects while building prerequisites within each track. Linux and Ansible demonstrations will use disposable practice environments; no production systems or personal data are needed.

Some lessons explain a concept through a physical activity. Lessons showing commands, code or model results will include the exact example and its verified output in the guide. AI predictions can be wrong. Physical story actions are illustrations, not evidence that code controls real hardware.

Expect more scene-based problem solving, different camera compositions, meaningful character actions, and pauses to predict the result. New previews will identify the individual story rather than repeat a code-board layout.
