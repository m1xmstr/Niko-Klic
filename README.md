# Nico & Klic

**Tiny code. Big adventures.**

Nico and his robot friend Klic explore computers, coding, Linux, automation and AI through playful visual stories. Predict an outcome, watch an experiment, and check what happened. [See the broader curriculum](CURRICULUM.md), including upcoming Ansible, machine learning and LLM lessons.

[Watch the YouTube channel](https://www.youtube.com/@NicoAndKlic) · [Learning path](LEARNING-PATH.md)

**Release schedule:** Starting October 26, our baseline is two Shorts each weekday, at 10AM and 3PM Central. An original long review follows every ten new Shorts, targeting Friday evening or Saturday after the covered lessons are public and checked. The already-prepared five-lesson review for October 23 remains a transition exception. Quality checks can delay a release.

[Community lesson posts](https://www.youtube.com/@NicoAndKlic/posts) add a descriptive lesson title, learning objective, video and the matching GitHub guide as each lesson is published.

## About the series

The stories use original synthetic character voices, generated illustrations, and animated lesson objects. Earlier lessons introduce terminology with labeled visual pseudocode; Episodes 44–115 focus on runnable Python, separate terminal output, and changed examples. The new rotation begins with Linux and Ansible concept models; their guides clearly distinguish physical models from executed software. Longer explanations and adult-supported activities help turn a quick story into learning.

This public repository contains educational companion material. Production artwork, voice files, and production systems are managed separately. No commercial links or advertising are part of the show.
